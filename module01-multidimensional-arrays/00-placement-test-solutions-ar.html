Q6
الأنواع الأساسية
متى يعني + «الجمع» ومتى يعني «دمج النصوص»
System.out.println(1 + 2 + "3"); System.out.println("1" + 2 + 3);

القاعدة الأساسية: تقرأ جافا + من اليسار إلى اليمين خطوةً خطوة. بين عددين يقوم + بـالجمع. أمّا إذا كان أحد الطرفين نصًّا String (بين علامتَي اقتباس) فإنّ + يدمج النصوص (وتُسمّى concatenation). لنقرأ كلّ جملة خطوة بخطوة.

الجملة 1System.out.println(1 + 2 + "3");

الخطوة 1: 1 + 2 — كلاهما عددان ← جمع ← 3.

الخطوة 2: 3 + "3" — الآن أحد الطرفين نص ← دمج ← "33".

1 + 2 + "3" → 3 + "3" → "33"
الجملة 2System.out.println("1" + 2 + 3);

الخطوة 1: "1" + 2 — يبدأ بنص ← دمج ← "12".

الخطوة 2: "12" + 3 — لا يزال نصًّا ← دمج ← "123".

"1" + 2 + 3 → "12" + 3 → "123"
✅ الإجابة: 33 and 123
الرموز نفسها لكن ترتيب مختلف — لأنّه بمجرّد ظهور نص String يصبح كلّ + بعده دمجًا للنصوص.
💡 تذكّر
ترتيب القراءة مهم. استخدم الأقواس عندما تقصد الحساب: "Sum = " + (1 + 2) يطبع Sum = 3 وليس Sum = 12.

تعريف المصفوفة وإنشاؤها وتهيئتها

لنقرأ هذا البرنامج جملةً جملة. الجملة الأولى تقوم بثلاث مهام في صمت — التعريف والإنشاء والتهيئة — لذا سنرسم كلّ واحدة منها.

الجملة 1int[] marks = new int[3];

2) الإنشاء. الجزء new int[3] يطلب من جافا بناء مصفوفة حقيقية من 3 أعداد صحيحة في الذاكرة. 3) التهيئة. وعند إنشاء المصفوفة بهذه الطريقة تملأ جافا كلّ خانة تلقائيًا بالقيمة الافتراضية، وهي للنوع int تساوي 0.

✅ مَن يُنشئ المصفوفة ومرجعها فعلًا؟

نظام التشغيل لا يوزّع عنوانًا لكلّ مصفوفة. نظام التشغيل يعطي جافا كتلة واحدة كبيرة من الذاكرة عند تشغيل البرنامج. بعد ذلك تقرّر آلة جافا الافتراضية (JVM) بنفسها مكان كلّ مصفوفة جديدة وتنتج مرجعها. أنت لا ترى العنوان الحقيقي ولا تختاره — الـ JVM تديره. وعندما لا يشير أيّ متغيّر إلى مصفوفة، يقوم جامع المهملات (garbage collector) في الـ JVM بتحرير تلك الذاكرة تلقائيًا.
