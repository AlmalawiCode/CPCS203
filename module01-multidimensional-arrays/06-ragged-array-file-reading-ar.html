CPCS203 - هياكل البيانات

1 ما هي المصفوفة المتعرّجة؟

تعريف المصفوفة المتعرّجة (Ragged Array)

المصفوفة المتعرّجة (ragged array) (وتُسمى أيضًا المصفوفة المُسنّنة (jagged array)) هي مصفوفة ثنائية الأبعاد يمكن أن يحتوي فيها كل صف على عدد مختلف من الأعمدة. وهذا مثالي للبيانات الواقعية مثل درجات الطلاب، حيث قد يكون الطلاب المختلفون قد سجّلوا في أعداد مختلفة من المقررات!

في هذا الدرس، سنتعلّم كيفية قراءة مصفوفة متعرّجة من درجات الطلاب من ملف نصي. قد يكون لكل طالب عدد مختلف من الدرجات، مما يجعل هذه حالة استخدام مثالية للمصفوفات المتعرّجة.

مثال: مصفوفة متعرّجة لدرجات الطلاب
Student 0:
10
20
Student 1:
9
18
30
20
10
Student 2:
10
15
Student 3:
5

لماذا المصفوفات المتعرّجة؟

لاحظ كيف أن لكل طالب عددًا مختلفًا من الدرجات. الطالب 1 (Student 1) لديه 5 درجات بينما الطالبان 0 و2 لديهما درجتان فقط. المصفوفة الثنائية الأبعاد العادية ستهدر الذاكرة بتخصيص الحجم نفسه لجميع الصفوف!

2 نظرة عامة على تنسيق الملف

ملف الإدخال لدينا marks.txt له بنية بسيطة:

marks.txt
4 // Number of students
10 20 // Student 0: 2 marks
9 18 30 20 10 // Student 1: 5 marks
10 15 // Student 2: 2 marks
5 20 26 // Student 3: 3 marks
شرح بنية الملف
  • السطر الأول يحتوي على عدد الطلاب (4)
  • كل سطر تالٍ يحتوي على عدد متغيّر من الدرجات لذلك الطالب
  • الدرجات في كل سطر مفصولة بـمسافات

3 خوارزمية القراءة: خطوة بخطوة

سنستخدم nextLine() وsplit() لقراءة الملف وتحليله:

  1. اقرأ السطر الأول للحصول على عدد الطلاب (numStudents).
  2. أنشئ مصفوفة ثنائية الأبعاد بحجم [numStudents][].
    لاحظ القوس الثاني الفارغ [] - نحن لا نعرف حجم الأعمدة بعد!
  3. لكل سطر متبقٍّ:
    • اقرأ السطر بأكمله كسلسلة نصية (string)
    • قسّمه عند المسافات باستخدام split("\\s+")
    • حوّل كل رمز (token) إلى int
    • أسنِد المصفوفة أحادية البعد الناتجة إلى studentMarks[i]
ما هو \\s+؟

النمط \\s+ هو تعبير نمطي (regular expression) يطابق واحدًا أو أكثر من محارف المسافة البيضاء (مسافات، علامات جدولة، إلخ). وهذا يعالج الحالات التي قد تُفصل فيها الأرقام بأكثر من مسافة واحدة.

4 تنزيل الملفات

نزّل كلا الملفين لتشغيل المثال. ضعهما في المجلد نفسه!

كيفية التشغيل
  1. نزّل كلا الملفين إلى المجلد نفسه
  2. افتح نافذة طرفية/موجّه أوامر (terminal/command prompt) في ذلك المجلد
  3. الترجمة (Compile): javac RaggedArrayReader.java
  4. التشغيل (Run): java RaggedArrayReader

5 كود جافا الكامل

RaggedArrayReader.java 
 1// RaggedArrayReader.java
 2import java.io.File;
 3import java.io.FileNotFoundException;
 4import java.util.Scanner;
 5
 6public class RaggedArrayReader {
 7    public static void main(String[] args) {
 8        try {
 9            // Create Scanner to read from file
10            Scanner fileReader = new Scanner(new File("marks.txt"));
11
12            // Step 1: Read number of students from the first line
13            int numStudents = Integer.parseInt(fileReader.nextLine());
14
15            // Step 2: Create a ragged array (only first dimension specified!)
16            int[][] studentMarks = new int[numStudents][];
17
18            // Step 3: For each student, read their line of marks
19            for (int i = 0; i < numStudents; i++) {
20                // Check if there's another line to read
21                if (!fileReader.hasNextLine()) {
22                    System.err.println("Not enough lines for " + numStudents + " students!");
23                    break;
24                }
25
26                // Read the entire line of marks
27                String line = fileReader.nextLine().trim();
28
29                // Split by one or more spaces (regex: \s+)
30                String[] tokens = line.split("\\s+");
31
32                // Convert string tokens to integers
33                int[] marks = new int[tokens.length];
34                for (int j = 0; j < tokens.length; j++) {
35                    marks[j] = Integer.parseInt(tokens[j]);
36                }
37
38                // Assign this 1D array to the ragged array
39                studentMarks[i] = marks;
40            }
41
42            // Close the file
43            fileReader.close();
44
45            // Print the ragged array to verify
46            System.out.println("Ragged array of student marks:");
47            for (int i = 0; i < studentMarks.length; i++) {
48                System.out.print("Student " + (i + 1) + ": ");
49                for (int mark : studentMarks[i]) {
50                    System.out.print(mark + " ");
51                }
52                System.out.println();
53            }
54
55        } catch (FileNotFoundException e) {
56            System.err.println("File not found: " + e.getMessage());
57        }
58    }
59}

6 شرح الكود - سطرًا بسطر

دعونا نمرّ على كل سطر من الكود لكي تفهم بالضبط كيف تكتبه بنفسك!

الجزء 1: عبارات الاستيراد (Import Statements) (الأسطر 2-4)

السطر 2: import java.io.File;

ماذا يفعل: يستورد الصنف File من مكتبة الإدخال/الإخراج (I/O) في جافا.

لماذا نحتاجه: الصنف File يمثّل ملفًا على حاسوبك. نستخدمه لنُخبر الـ Scanner بأي ملف يجب أن يقرأ.

السطر 3: import java.io.FileNotFoundException;

ماذا يفعل: يستورد صنف الاستثناء FileNotFoundException.

لماذا نحتاجه: عندما نحاول فتح ملف، قد لا يكون موجودًا! تُجبرنا جافا على معالجة هذا الاحتمال باستخدام try-catch.

السطر 4: import java.util.Scanner;

ماذا يفعل: يستورد الصنف Scanner.

لماذا نحتاجه: الـ Scanner هو أداتنا لقراءة البيانات. لقد استخدمناه مع System.in للإدخال من لوحة المفاتيح - والآن سنستخدمه مع File للقراءة من ملف!

الجزء 2: فتح الملف (الأسطر 8-10)

السطر 8: try {

ماذا يفعل: يبدأ كتلة try لمعالجة الاستثناءات.

لماذا نحتاجه: عمليات الملفات قد تفشل (الملف غير موجود، لا توجد صلاحية، إلخ). كتلة try تتيح لنا محاولة العملية ومعالجة الأخطاء بأناقة.

السطر 10: Scanner fileReader = new Scanner(new File("marks.txt"));

هذا السطر يقوم بأمرين:

  1. new File("marks.txt") - ينشئ كائن File يشير إلى "marks.txt" في المجلد الحالي
  2. new Scanner(...) - ينشئ Scanner يقرأ من ذلك الـ File

فكّر فيه هكذا: "افتح الملف marks.txt وأعطني Scanner لأقرأه"

الجزء 3: قراءة عدد الطلاب (السطر 13)

السطر 13: int numStudents = Integer.parseInt(fileReader.nextLine());

هذا السطر يقوم بثلاثة أمور (اقرأه من الداخل إلى الخارج):

  1. fileReader.nextLine() - يقرأ السطر الأول بأكمله كسلسلة نصية (String) (مثل "4")
  2. Integer.parseInt(...) - يحوّل السلسلة النصية "4" إلى العدد الصحيح 4
  3. int numStudents = ... - يخزّن النتيجة في المتغيّر numStudents
بعد هذا السطر: numStudents = 4 (لدينا 4 طلاب)

الجزء 4: إنشاء المصفوفة المتعرّجة (السطر 16)

السطر 16: int[][] studentMarks = new int[numStudents][];

ماذا يفعل: ينشئ مصفوفة ثنائية الأبعاد مع تحديد البُعد الأول فقط!

تفصيله:

  • int[][] - يُعلن عن مصفوفة ثنائية الأبعاد من الأعداد الصحيحة
  • new int[numStudents][] - ينشئ مصفوفة من 4 صفوف، لكن كل صف يساوي null (لا أعمدة بعد!)
تصوّر الذاكرة بعد هذا السطر:
studentMarks[0] = null
studentMarks[1] = null
studentMarks[2] = null
studentMarks[3] = null

لماذا البُعد الثاني فارغ؟ لأننا لا نعرف بعد كم درجة لدى كل طالب! سنملأ كل صف عندما نقرأه.

الجزء 5: الحلقة الرئيسية (الأسطر 19-40)

السطر 19: for (int i = 0; i < numStudents; i++) {

ماذا يفعل: يمرّ على كل طالب (0، 1، 2، 3).

في كل دورة (iteration): يقرأ سطرًا واحدًا من الملف وينشئ صفًا واحدًا في مصفوفتنا المتعرّجة.

الأسطر 21-24: التحقق من الأخطاء

if (!fileReader.hasNextLine()) { ... break; }

ماذا يفعل: يتحقق مما إذا كان هناك سطر آخر لقراءته.

لماذا نحتاجه: تحقّق أمان! إذا كان الملف يحتوي على أسطر أقل من المتوقّع، نتوقّف بأناقة بدلًا من الانهيار.

السطر 27: String line = fileReader.nextLine().trim();

هذا السطر يقوم بأمرين:

  1. fileReader.nextLine() - يقرأ السطر التالي بأكمله (مثل "10 20")
  2. .trim() - يزيل المسافات في البداية والنهاية
مثال (الدورة الأولى i=0):
سطر الملف: "10 20"
بعد trim: "10 20" (مخزَّن في line)
السطر 30: String[] tokens = line.split("\\s+");

ماذا يفعل: يقسّم السلسلة النصية عند المسافة البيضاء إلى مصفوفة من السلاسل النصية.

التعبير النمطي \\s+ يعني:

  • \\s - أي محرف مسافة بيضاء (مسافة، علامة جدولة، إلخ)
  • + - واحد أو أكثر منها
مثال:
الإدخال: "10 20"
النتيجة: tokens[0] = "10"، tokens[1] = "20"
tokens.length = 2
السطر 33: int[] marks = new int[tokens.length];

ماذا يفعل: ينشئ مصفوفة أحادية البعد جديدة من الأعداد الصحيحة بالحجم المطلوب بالضبط.

لماذا tokens.length؟ عدد الرموز (tokens) يخبرنا بعدد الدرجات التي لدى هذا الطالب!

مثال:
إذا كان tokens.length = 2، يُنشئ marks = new int[2]
إذا كان tokens.length = 5، يُنشئ marks = new int[5]
الأسطر 34-36: تحويل السلاسل النصية إلى أعداد صحيحة

for (int j = 0; j < tokens.length; j++) {
    marks[j] = Integer.parseInt(tokens[j]);
}

ماذا يفعل: يمرّ على كل سلسلة رمزية (token) ويحوّلها إلى عدد صحيح.

مثال:
tokens[0] = "10" → marks[0] = 10
tokens[1] = "20" → marks[1] = 20
السطر 39: studentMarks[i] = marks;

ماذا يفعل: يُسنِد مصفوفتنا أحادية البعد المُنشأة حديثًا إلى الصف i من المصفوفة المتعرّجة.

هذه هي الخطوة الأساسية! نحن نستبدل null بمصفوفة فعلية.

بعد الدورة الأولى (i=0):
studentMarks[0] = {10, 20} ← الآن لديه بيانات!
studentMarks[1] = null
studentMarks[2] = null
studentMarks[3] = null

الجزء 6: إغلاق الملف (السطر 43)

السطر 43: fileReader.close();

ماذا يفعل: يغلق الملف ويحرّر موارد النظام.

لماذا هو مهم: أغلق الملفات دائمًا عند الانتهاء! ترك الملفات مفتوحة قد يسبّب تسرّبًا في الذاكرة ويمنع البرامج الأخرى من الوصول إلى الملف.

الجزء 7: طباعة النتائج (الأسطر 46-53)

السطر 47: for (int i = 0; i < studentMarks.length; i++) {

ماذا يفعل: يمرّ على كل طالب (كل صف).

studentMarks.length يعطينا عدد الصفوف (الطلاب).

السطر 49: for (int mark : studentMarks[i]) {

ماذا يفعل: حلقة for المحسّنة (enhanced for-loop) التي تمرّ على كل درجة في مصفوفة الطالب i.

لماذا حلقة for المحسّنة؟ كل صف له طول مختلف! حلقة for المحسّنة تعالج هذا تلقائيًا.

لأجل studentMarks[0] = {10, 20}: تدور مرتين
لأجل studentMarks[1] = {9, 18, 30, 20, 10}: تدور خمس مرات

الجزء 8: معالجة الاستثناءات (الأسطر 55-57)

الأسطر 55-57: catch (FileNotFoundException e) { ... }

ماذا يفعل: يلتقط الاستثناء إذا كان الملف غير موجود.

ماذا يحدث: إذا لم يُعثر على "marks.txt"، يطبع البرنامج رسالة خطأ بدلًا من الانهيار.

e.getMessage() يعطي تفاصيل عمّا حدث خطأ.

تتبّع التنفيذ الكامل

التنفيذ خطوة بخطوة مع marks.txt
الخطوة الإجراء النتيجة

8 أهم النقاط المستفادة

الخلاصة
  • المصفوفات المتعرّجة (Ragged arrays) تسمح بأحجام صفوف مختلفة - مثالية للبيانات متغيّرة الطول
  • استخدم new int[n][] لإنشاء مصفوفة مع تحديد البُعد الأول فقط
  • nextLine() يقرأ سطرًا كاملًا كسلسلة نصية
  • split("\\s+") يقسّم سلسلة نصية عند المسافة البيضاء إلى مصفوفة
  • Integer.parseInt() يحوّل سلسلة نصية إلى عدد صحيح
  • أسنِد كل صف على حدة: array[i] = new int[size]
