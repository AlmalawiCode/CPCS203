Model Answer — Q10
public static double[] dailyAverage(double[][] temp) {
    double[] avg = new double[temp[0].length];   // one per day
    for (int day = 0; day < temp[0].length; day++) {
        double total = 0;
        for (int city = 0; city < temp.length; city++) {
            total += temp[city][day];
        }
        avg[day] = total / temp.length;
    }
    return avg;
}

public static int hottestCity(double[][] temp) {
    int best = 0;
    double bestTotal = 0;
    for (int j = 0; j < temp[0].length; j++) {   // row 0 first
        bestTotal += temp[0][j];
    }
    for (int i = 1; i < temp.length; i++) {
        double total = 0;
        for (int j = 0; j < temp[i].length; j++) {
            total += temp[i][j];
        }
        if (total > bestTotal) {    // > keeps the smaller index
            bestTotal = total;
            best = i;
        }
    }
    return best;
}

(a) result array of size temp[0].length (1) · outer loop over columns, inner over rows (1) · correct sum (1) · divide by temp.length and return (1). (b) start from row 0’s sum (1) · sum of each row (1) · compare with > and keep the index (1) · return the index, not the sum (1). Tested with the data above: it prints exactly the expected output.

public static int[][] readSales(String fileName)
                                throws FileNotFoundException {
    Scanner in = new Scanner(new File(fileName));
    int n = Integer.parseInt(in.nextLine().trim());  // line 1
    int[][] sales = new int[n][];          // rows are null for now
    for (int i = 0; i < n; i++) {
        String[] tokens = in.nextLine().trim().split("\\s+");
        sales[i] = new int[tokens.length]; // exact row size
        for (int j = 0; j < tokens.length; j++) {
            sales[i][j] = Integer.parseInt(tokens[j]);
        }
    }
    in.close();
    return sales;
}

public static void main(String[] args)
                        throws FileNotFoundException {
    int[][] sales = readSales("sales.txt");
    int best = 0;
    double bestAvg = -1;
    for (int i = 0; i < sales.length; i++) {
        int total = 0;
        for (int j = 0; j < sales[i].length; j++) {
            total += sales[i][j];
        }
        System.out.println("Branch " + i + ": total " + total
                           + " in " + sales[i].length + " day(s)");
        double avg = (double) total / sales[i].length;
        if (avg > bestAvg) {
            bestAvg = avg;
            best = i;
        }
    }
    System.out.println("Best daily average: branch " + best
                       + " (" + bestAvg + ")");
}

(a) 1 mark for all three. (b) open the file with new Scanner(new File(fileName)) and read the count (1) · new int[n][] (1) · split each line and create the row with tokens.length (1) · parseInt into the row and return (1).
