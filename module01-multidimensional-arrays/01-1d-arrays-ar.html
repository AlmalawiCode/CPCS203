1 ما هو البرنامج؟

قبل أن نتعلم المصفوفات (Arrays)، لا بد أن نفهم الأساسيات. يتكوّن البرنامج من مكوّنين جوهريين:

مكوّنات البرنامج
التعليمات (Instructions)
ما الذي يجب فعله (الشيفرة)
+
البيانات (Data)
ما الذي نعمل عليه
سؤال جوهري: أين تُخزّن البيانات؟

تُخزّن البيانات في الذاكرة (RAM). لكن كيف تُخزّن بالضبط؟ يقودنا هذا إلى فهم أنواع البيانات (Data Types).

3 لماذا نحتاج إلى المصفوفات (Arrays)؟

دعونا نتأمّل سيناريو واقعيًا:

سيناريو: تخزين أعمار الطلاب

تحتاج إلى تخزين أعمار 100 طالب في برنامجك. كيف ستفعل ذلك؟

بدون مصفوفات
int age1 = 20; int age2 = 21; int age3 = 19; int age4 = 22; // ... 96 more lines! int age100 = 20;

100 متغيّر! يصعب التحكم بها!

مع المصفوفات
int[] ages; ages = new int[100]; // One variable to manage // all 100 ages!

مقبض واحد لـ 100 قيمة!

الحل: المصفوفات (Arrays)!

المصفوفة هي متغيّر واحد يمكنه تخزين قيم متعددة من النوع نفسه في مواقع ذاكرة متجاورة.

عناوين الذاكرة متتالية (متجاورة)

خصائص المصفوفات

1
متجانسة (نوع واحد)

يمكن للمصفوفة تخزين عناصر من نوع بيانات واحد فقط. لا يمكنك خلط الأعداد الصحيحة والنصوص في المصفوفة نفسها.

2
حجم ثابت

بمجرد إنشاء المصفوفة، لا يمكن تغيير حجمها. يجب أن تعرف الحجم قبل إنشائها.

3
ذاكرة متجاورة

تُخزّن العناصر في مواقع ذاكرة متلاصقة، مما يجعل الوصول إليها فعّالًا جدًا (باستخدام حساب الإزاحة).

4
الترقيم يبدأ من الصفر

يقع العنصر الأول عند الفهرس 0، وليس 1. فمصفوفة حجمها 5 لها الفهارس 0 و1 و2 و3 و4.

لماذا تكون الذاكرة المتجاورة فعّالة؟

عندما تصل إلى ages[3]، يحسب الحاسوب:

address = base_address + (index × size_of_element)

ستتعلم المزيد عن هذا في مقرر أنظمة التشغيل (إدارة الذاكرة).

5 الخطوات الثلاث الأساسية

فهم بالغ الأهمية

يخلط كثير من الطلاب بين هذه الخطوات الثلاث. فهمها ضروري لمقرر هياكل البيانات!

1
التصريح (Declaration)

إنشاء متغيّر مرجعي (reference variable) سيحمل عنوان المصفوفة.

int[] ages; // Declares a reference variable

ذاكرة الكومة (Heap)

مهم!

المتغيّر المرجعي ages لا يحتوي على بيانات المصفوفة! إنه يحمل فقط العنوان (المرجع) المؤدي إلى المكان الذي ستُخزّن فيه المصفوفة. حاليًا، يحمل القيمة null (لا شيء).

2
الإنشاء (Creation / Instantiation)

تخصيص ذاكرة للمصفوفة الفعلية باستخدام الكلمة المفتاحية new.

ages = new int[5]; // Creates array of 5 integers

القيم الافتراضية: عند إنشاء المصفوفة، تُهيّأ جميع عناصرها بقيم افتراضية:

  • int وshort وbyte وlong ← 0
  • float وdouble ← 0.0
  • boolean ← false
  • char ← '' (المحرف الفارغ)
  • الأنواع المرجعية ← null
3

ages[0] = 20; ages[1] = 21; ages[2] = 19; ages[3] = 22; ages[4] = 20;

الصيغة المختصرة

يمكنك دمج الخطوات الثلاث كلها في سطر واحد:

// Method 1: Declaration + Creation + Initialization int[] ages = new int[] { 20, 21, 19, 22, 20 }; // Method 2: Even shorter (array literal) int[] ages = { 20, 21, 19, 22, 20 };

6 فهم المتغيّرات المرجعية (Reference Variables)

جوهري لمقرر هياكل البيانات!

فهم المتغيّرات المرجعية ضروري تمامًا لمقرر هياكل البيانات لديك. انتبه جيدًا لهذا القسم!

دعونا نرى ما الذي يحدث عندما نُسند متغيّر مصفوفة إلى آخر:

int[] ages = { 20, 21, 19 }; int[] scores = ages; // What happens here?
مرجعان، ومصفوفة واحدة فقط!
ذاكرة المكدّس (Stack)
ages
0x7A3F
scores
0x7A3F
ذاكرة الكومة (Heap) (0x7A3F)
[0]
20
[1]
21
[2]
19
فهم أساسي

كلٌّ من ages وscores يشير إلى المصفوفة نفسها في الذاكرة! فإذا غيّرت scores[0]، تتغيّر أيضًا قيمة ages[0] لأنهما يشيران إلى البيانات نفسها.

scores[0] = 100; System.out.println(ages[0]); // Output: 100 (not 20!) System.out.println(scores[0]); // Output: 100

7 التمرير بالقيمة مقابل التمرير بالمرجع (Pass by Value vs Pass by Reference)

فهم كيفية تمرير البيانات إلى الدوال (Methods) أمر بالغ الأهمية لكتابة برامج صحيحة.

التمرير بالقيمة (الأنواع البدائية)
public class Test { public static void changeAge(int x) { x = 100; } public static void main(String[] args) { int age = 20; changeAge(age); System.out.println(age); // Output: 20 } }
الأصل
age = 20
النسخة (داخل الدالة)
x = 20 → 100

تُمرّر نسخة من القيمة. والتغييرات على النسخة لا تؤثر في الأصل.

التمرير بالمرجع (المصفوفات)
public class Test { public static void changeArray(int[] arr) { arr[0] = 100; } public static void main(String[] args) { int[] ages = {20, 21}; changeArray(ages); System.out.println(ages[0]); // Output: 100 } }
ages (مرجع)
0x7A3F
arr (نسخة من المرجع)
0x7A3F
↓ كلاهما يشير إلى ↓
[100, 21]

يُنسخ المرجع (العنوان). وكلاهما يشير إلى المصفوفة نفسها!

الخلاصة الأساسية:

  • الأنواع البدائية: تُنسخ القيمة الفعلية. والأصل يبقى آمنًا.
  • المصفوفات/الكائنات: يُنسخ المرجع. وكلا المتغيّرين يصل إلى البيانات نفسها!

8 الملخّص وما هو التالي

أهم النقاط المستفادة اليوم
  1. تتكوّن البرامج من تعليمات وبيانات
  2. أنواع البيانات: بدائية (8 أنواع) مقابل مرجعية (المصفوفات والكائنات)
  3. تخزّن المصفوفات قيمًا متعددة من النوع نفسه في ذاكرة متجاورة
  4. ثلاث خطوات: التصريح ← الإنشاء ← التهيئة
  5. تحمل المتغيّرات المرجعية عناوين، وليست بيانات فعلية
  6. التمرير بالقيمة ينسخ القيم؛ والتمرير بالمرجع يشارك البيانات نفسها
