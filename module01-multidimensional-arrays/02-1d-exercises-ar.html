CompareArrays.java 
1int[] arr1 = {1, 2, 3};

لماذا هما غير متساويين؟ دعونا نتخيّل ذلك!
رغم أن كلتا المصفوفتين تحتويان على {1, 2, 3}، إلا أنهما مخزَّنتان في مواقع مختلفة في الذاكرة:

Address: 0x5C7D
[0]1

💡
فكرة أساسية: يقارن المُعامل == بين عناوين الذاكرة (المراجع)، وليس بين القيم الموجودة داخل المصفوفات! وبما أن arr1 و arr2 يشيران إلى موقعين مختلفين (0x1A2B مقابل 0x5C7D)، فهما غير متساويين.
لمقارنة محتويات المصفوفة: استخدم Arrays.equals(arr1, arr2) التي تُرجع true لأن القيم متطابقة.

تتبّع الكود
ما ناتج الكود التالي؟
SameReference.java 
1int[] arr1 = {1, 2, 3};
2int[] arr2 = arr1;  // arr2 points to same array as arr1
3
4if (arr1 == arr2) {
5    System.out.println("Equal");
6} else {
7    System.out.println("Not Equal");
8}
لماذا هما متساويان؟ دعونا نتخيّل ذلك!
عندما نكتب arr2 = arr1، فإننا ننسخ المرجع (العنوان)، وليس المصفوفة. والآن يشير كلاهما إلى المصفوفة نفسها:
ذاكرة المكدّس (Stack)
arr1
0x1A2B
arr2
0x1A2B
arr1 == arr2
0x1A2B = 0x1A2B
TRUE!
ذاكرة الكومة (Heap)
Address: 0x1A2B (SAME!)
[0]1
[1]2
[2]3
توجد مصفوفة واحدة فقط!
💡
فكرة أساسية: يحمل كلٌّ من arr1 و arr2 العنوان نفسه (0x1A2B). ويقارن المُعامل == بين هذين العنوانين، وبما أنهما متطابقان، تكون النتيجة true!
مهم: بما أن كلا المتغيرين يشيران إلى المصفوفة نفسها، فإن تغيير arr2[0] سيغيّر أيضًا arr1[0]! فهما يتشاركان البيانات نفسها.
الجزء 3: التمرير بالقيمة مقابل التمرير بالمرجع (Pass by Value vs Reference)
8
تتبّع الكود
ما قيمة x بعد استدعاء الدالة (method)؟
PassByValue.java 
 1public static void changeValue(int num) {
 2    num = 100;
 3}
 4
 5public static void main(String[] args) {
 6    int x = 5;
 7    changeValue(x);
 8    System.out.println(x);  // What is printed?
 9}
9
تتبّع الكود
ما قيمة arr[0] بعد استدعاء الدالة (method)؟
PassByReference.java 
 1public static void changeArray(int[] nums) {
 2    nums[0] = 100;
 3}
 4
 5public static void main(String[] args) {
 6    int[] arr = {5, 10, 15};
 7    changeArray(arr);
 8    System.out.println(arr[0]);  // What is printed?
 9}
10
اختيار من متعدد
في السؤال 8، بقيت قيمة x تساوي 5. وفي السؤال 9، تغيّرت قيمة arr[0] إلى 100. لماذا حدث ذلك؟
