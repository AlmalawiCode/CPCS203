CPCS203 - هياكل البيانات

1 ما هي المصفوفة غير المنتظمة ثلاثية الأبعاد؟

تعريف المصفوفة غير المنتظمة ثلاثية الأبعاد

المصفوفة غير المنتظمة ثلاثية الأبعاد (3D Ragged Array) هي مصفوفة ثلاثية الأبعاد حيث:

  • يمكن أن يكون لكل قسم عدد مختلف من الطلاب
  • يمكن أن يكون لكل طالب عدد مختلف من المقررات

هذا مثالي لبيانات الجامعات في العالم الحقيقي!

السيناريو لدينا: أقسام الجامعة

لدينا 3 أقسام، يُعرَّف كل منها بفهرس (index):

الفهرس اسم القسم الاختصار
0 علوم الحاسب (Computer Science) CS
1 تقنية المعلومات (Information Technology) IT
2 نظم المعلومات (Information Systems) IS
بنية المصفوفة

marks[department][student][course]

  • الفهرس الأول: أي قسم (0=CS، 1=IT، 2=IS)
  • الفهرس الثاني: أي طالب في ذلك القسم
  • الفهرس الثالث: أي درجة مقرر لذلك الطالب

شرح بنية الملف
  • السطر 1: عدد الأقسام (3)
  • السطر 2: عدد الطلاب في كل قسم (2 3 2 تعني CS=2، IT=3، IS=2)
  • الأسطر المتبقية: سطر واحد لكل طالب يحتوي على درجات مقرراته (بطول متغيّر!)
كم عدد الأسطر إجمالاً؟

2 (header lines) + 2 (CS students) + 3 (IT students) + 2 (IS students) = 9 lines

4 خوارزمية القراءة: خطوة بخطوة

الخطوة 1: قراءة عدد الأقسام

اقرأ السطر 1 ← numDepartments = 3

الخطوة 2: قراءة عدد الطلاب لكل قسم

اقرأ السطر 2 ← "2 3 2"

قسّم وحوّل ← studentsPerDept = {2, 3, 2}

الخطوة 3: إنشاء المصفوفة غير المنتظمة ثلاثية الأبعاد

int[][][] marks = new int[numDepartments][][];

هذا يُنشئ: [null, null, null] - مجرد 3 خانات فارغة للأقسام

الخطوة 4: لكل قسم (الحلقة الخارجية)

أنشئ مصفوفة ثنائية الأبعاد للطلاب:

marks[d] = new int[studentsPerDept[d]][];

عند d=0 (CS): marks[0] = new int[2][]; ← يُنشئ مساحة لطالبين

عند d=1 (IT): marks[1] = new int[3][]; ← يُنشئ مساحة لـ 3 طلاب

عند d=2 (IS): marks[2] = new int[2][]; ← يُنشئ مساحة لطالبين

الخطوة 5: لكل طالب (الحلقة الداخلية)
  • اقرأ السطر بأكمله كسلسلة نصية (string)
  • قسّمه عند المسافات البيضاء باستخدام split("\\s+")
  • حوّل كل رمز (token) إلى int
  • أسنده إلى marks[d][s]

5 تنزيل الملفات

نزّل كلا الملفين لتشغيل المثال. ضعهما في المجلد نفسه!

كيفية التشغيل
  1. نزّل كلا الملفين إلى المجلد نفسه
  2. افتح الطرفية/موجّه الأوامر (terminal/command prompt) في ذلك المجلد
  3. الترجمة (Compile): javac Ragged3DReader.java
  4. التشغيل (Run): java Ragged3DReader

6 كود جافا الكامل

Ragged3DReader.java 
 1// Ragged3DReader.java
 2import java.io.File;
 3import java.io.FileNotFoundException;
 4import java.util.Scanner;
 5
 6public class Ragged3DReader {
 7    public static void main(String[] args) {
 8        // Department names for display (index 0=CS, 1=IT, 2=IS)
 9        String[] deptNames = {"CS", "IT", "IS"};
10
11        try {
12            // Create Scanner to read from file
13            Scanner fileReader = new Scanner(new File("departments.txt"));
14
15            // ============ STEP 1: Read number of departments ============
16            int numDepartments = Integer.parseInt(fileReader.nextLine().trim());
17
18            // ============ STEP 2: Read students per department ============
19            String studentsLine = fileReader.nextLine().trim();
20            String[] studentTokens = studentsLine.split("\\s+");
21
22            // Convert to int array: studentsPerDept[d] = number of students in dept d
23            int[] studentsPerDept = new int[numDepartments];
24            for (int d = 0; d < numDepartments; d++) {
25                studentsPerDept[d] = Integer.parseInt(studentTokens[d]);
26            }
27
28            // ============ STEP 3: Create 3D ragged array ============
29            // Only first dimension specified!
30            int[][][] marks = new int[numDepartments][][];
31
32            // ============ STEP 4 & 5: Read marks for each department and student ============
33            for (int d = 0; d < numDepartments; d++) {
34                // Create 2D array for this department's students
35                marks[d] = new int[studentsPerDept[d]][];
36
37                // For each student in this department
38                for (int s = 0; s < studentsPerDept[d]; s++) {
39                    // Read the line of course marks
40                    String line = fileReader.nextLine().trim();
41
42                    // Split by whitespace
43                    String[] tokens = line.split("\\s+");
44
45                    // Create array for this student's courses
46                    int[] courses = new int[tokens.length];
47
48                    // Convert each token to int
49                    for (int c = 0; c < tokens.length; c++) {
50                        courses[c] = Integer.parseInt(tokens[c]);
51                    }
52
53                    // Assign to the 3D array
54                    marks[d][s] = courses;
55                }
56            }
57
58            // Close the file
59            fileReader.close();
60
61            // ============ PRINT THE 3D RAGGED ARRAY ============
62            System.out.println("3D Ragged Array of Department Marks:");
63            System.out.println("====================================");
64
65            for (int d = 0; d < marks.length; d++) {
66                System.out.println("\nDepartment " + d + " (" + deptNames[d] + "):");
67
68                for (int s = 0; s < marks[d].length; s++) {
69                    System.out.print("  Student " + s + ": ");
70
71                    for (int mark : marks[d][s]) {
72                        System.out.print(mark + " ");
73                    }
74                    System.out.println("(" + marks[d][s].length + " courses)");
75                }
76            }
77
78        } catch (FileNotFoundException e) {
79            System.err.println("File not found: " + e.getMessage());
80        }
81    }
82}

7 شرح الكود - سطراً بسطر

دعونا نستعرض كل سطر من الكود حتى تفهم بالضبط كيف تكتبه بنفسك!

الجزء 1: الإعداد وأسماء الأقسام (الأسطر 1-13)

الأسطر 2-4: عبارات الاستيراد (Import Statements)

مثل النسخة ثنائية الأبعاد - نحتاج إلى File و FileNotFoundException و Scanner.

السطر 9: String[] deptNames = {"CS", "IT", "IS"};

ماذا يفعل: يُنشئ مصفوفة لربط أرقام الفهارس بأسماء الأقسام.

لماذا نحتاجه: الملف يستخدم الفهارس (0، 1، 2)، لكننا نريد عرض أسماء ذات معنى.

deptNames[0] = "CS"
deptNames[1] = "IT"
deptNames[2] = "IS"
السطر 13: Scanner fileReader = new Scanner(new File("departments.txt"));

ماذا يفعل: يفتح الملف "departments.txt" للقراءة.

تذكّر: يجب أن يكون الملف في المجلد نفسه الذي يوجد فيه ملف جافا!

الجزء 2: قراءة أسطر الترويسة (الأسطر 15-26)

السطر 16: int numDepartments = Integer.parseInt(fileReader.nextLine().trim());

ماذا يفعل: يقرأ السطر 1 من الملف ويحوّله إلى عدد صحيح.

خطوة بخطوة:

  1. fileReader.nextLine() ← يقرأ "3"
  2. .trim() ← يزيل أي مسافات إضافية
  3. Integer.parseInt() ← يحوّل إلى العدد الصحيح 3
بعد هذا السطر: numDepartments = 3
الأسطر 19-20: قراءة عدد الطلاب لكل قسم

String studentsLine = fileReader.nextLine().trim();

String[] studentTokens = studentsLine.split("\\s+");

ماذا يفعل:

  1. السطر 19: يقرأ "2 3 2" من الملف
  2. السطر 20: يقسّم عند المسافات البيضاء ← {"2", "3", "2"}
studentTokens[0] = "2" (قسم CS فيه طالبان)
studentTokens[1] = "3" (قسم IT فيه 3 طلاب)
studentTokens[2] = "2" (قسم IS فيه طالبان)
الأسطر 23-26: التحويل إلى مصفوفة أعداد صحيحة

int[] studentsPerDept = new int[numDepartments];

for (int d = 0; d < numDepartments; d++) {

    studentsPerDept[d] = Integer.parseInt(studentTokens[d]);

}

ماذا يفعل: يحوّل الرموز النصية (string tokens) إلى أعداد صحيحة.

بعد هذه الحلقة:
studentsPerDept = {2, 3, 2}

الجزء 3: إنشاء المصفوفة غير المنتظمة ثلاثية الأبعاد (السطر 30)

السطر 30: int[][][] marks = new int[numDepartments][][];

ماذا يفعل: يُنشئ مصفوفة ثلاثية الأبعاد بتحديد البُعد الأول فقط!

لاحظ: [][] فارغة - لا نعرف بعدُ عدد الطلاب أو المقررات!

تصوّر الذاكرة:
marks[0] = null (ستحمل طلاب CS)
marks[1] = null (ستحمل طلاب IT)
marks[2] = null (ستحمل طلاب IS)

الجزء 4: الحلقة الخارجية - لكل قسم (الأسطر 33-56)

السطر 33: for (int d = 0; d < numDepartments; d++) {

ماذا يفعل: يمرّ عبر كل قسم (d = 0، 1، 2).

تسمية المتغيّر: d اختصاراً لـ "department" (القسم)

السطر 35: marks[d] = new int[studentsPerDept[d]][];

ماذا يفعل: يُنشئ مصفوفة ثنائية الأبعاد لطلاب هذا القسم.

هذا هو المفتاح! يحصل كل قسم على عدد مختلف من خانات الطلاب:

عندما d=0 (CS): marks[0] = new int[2][]; ← خانتان للطلاب
عندما d=1 (IT): marks[1] = new int[3][]; ← 3 خانات للطلاب
عندما d=2 (IS): marks[2] = new int[2][]; ← خانتان للطلاب

ملاحظة: الـ [] في النهاية لا تزال فارغة - مقررات كل طالب ستتغيّر!

الجزء 5: الحلقة الداخلية - لكل طالب (الأسطر 38-55)

السطر 38: for (int s = 0; s < studentsPerDept[d]; s++) {

ماذا يفعل: يمرّ عبر كل طالب في القسم d.

تسمية المتغيّر: s اختصاراً لـ "student" (الطالب)

لاحظ: حدّ الحلقة هو studentsPerDept[d] - مختلف لكل قسم!

لقسم CS (d=0): يمرّ s = 0، 1 (طالبان)
لقسم IT (d=1): يمرّ s = 0، 1، 2 (3 طلاب)
لقسم IS (d=2): يمرّ s = 0، 1 (طالبان)
السطر 40: String line = fileReader.nextLine().trim();

ماذا يفعل: يقرأ السطر التالي من الملف (درجات طالب واحد).

مثال (التكرار الأول d=0، s=0):
يقرأ: "85 90 78" (درجات الطالب 0 في قسم CS)
السطر 43: String[] tokens = line.split("\\s+");

ماذا يفعل: يقسّم السطر عند المسافات البيضاء.

مثال:
الإدخال: "85 90 78"
النتيجة: tokens = {"85", "90", "78"}
tokens.length = 3 (هذا الطالب لديه 3 مقررات)
السطر 46: int[] courses = new int[tokens.length];

ماذا يفعل: يُنشئ مصفوفة أحادية البعد بالعدد الدقيق للمقررات لهذا الطالب.

لماذا tokens.length؟ عدد الرموز (tokens) يخبرنا بعدد المقررات!

طلاب مختلفون، أحجام مختلفة:
CS Student 0: tokens.length = 3 ← courses = new int[3]
CS Student 1: tokens.length = 4 ← courses = new int[4]
IT Student 1: tokens.length = 5 ← courses = new int[5]
الأسطر 49-51: تحويل الرموز إلى أعداد صحيحة

for (int c = 0; c < tokens.length; c++) {

    courses[c] = Integer.parseInt(tokens[c]);

}

تسمية المتغيّر: c اختصاراً لـ "course" (المقرر)

ماذا يفعل: يحوّل كل درجة نصية إلى عدد صحيح.

مثال:
tokens[0] = "85" ← courses[0] = 85
tokens[1] = "90" ← courses[1] = 90
tokens[2] = "78" ← courses[2] = 78
السطر 54: marks[d][s] = courses;

ماذا يفعل: يُسند مصفوفة المقررات إلى الموضع الصحيح في مصفوفتنا ثلاثية الأبعاد.

هذا هو الإسناد النهائي!

مثال (d=0، s=0):
marks[0][0] = {85, 90, 78}

المعنى: القسم 0 (CS)، الطالب 0، لديه الدرجات 85، 90، 78

الجزء 6: طباعة المصفوفة ثلاثية الأبعاد (الأسطر 61-76)

السطر 65: for (int d = 0; d < marks.length; d++) {

ماذا يفعل: الحلقة الخارجية عبر الأقسام.

marks.length = 3 (عدد الأقسام)

السطر 66: System.out.println("\nDepartment " + d + " (" + deptNames[d] + "):");

ماذا يفعل: يطبع ترويسة القسم مع الاسم.

مثال على المخرجات: Department 0 (CS):

السطر 68: for (int s = 0; s < marks[d].length; s++) {

ماذا يفعل: الحلقة الوسطى عبر الطلاب في القسم d.

marks[d].length = عدد الطلاب في ذلك القسم (متغيّر!)

السطر 71: for (int mark : marks[d][s]) {

ماذا يفعل: الحلقة الداخلية عبر مقررات الطالب s.

الحلقة المحسّنة (Enhanced for-loop): تتعامل تلقائياً مع أعداد المقررات المختلفة!

marks[d][s] = المصفوفة أحادية البعد للدرجات لهذا الطالب

السطر 74: System.out.println("(" + marks[d][s].length + " courses)");

ماذا يفعل: يطبع كم مقرراً لدى كل طالب.

marks[d][s].length = عدد المقررات لهذا الطالب المحدّد

9 الخلاصات الأساسية

ملخّص - المصفوفة غير المنتظمة ثلاثية الأبعاد
  • التصريح: int[][][] marks = new int[numDepts][][]; - البُعد الأول فقط!
  • إنشاء مصفوفة ثنائية لكل قسم: marks[d] = new int[studentsPerDept[d]][];
  • إنشاء مصفوفة أحادية لكل طالب: دع split() يحدّد الحجم
  • الإسناد: marks[d][s] = courses;
نمط الوصول

marks[department][student][course]

مثال: marks[1][2][0] = قسم IT، الطالب 2، المقرر 0 = 70

مقارنة المصفوفات غير المنتظمة ثنائية الأبعاد مقابل ثلاثية الأبعاد
الخاصية متعرّجة ثنائية الأبعاد متعرّجة ثلاثية الأبعاد
التصريح int[n][] int[n][][]
الحلقات المطلوبة 1 (الطلاب) 2 (الأقسام + الطلاب)
أسطر الترويسة 1 (العدد) 2 (العدد + الأحجام)
السابق: المصفوفات غير المنتظمة ثنائية الأبعاد → ← العودة إلى المصفوفات ثنائية وثلاثية الأبعاد
