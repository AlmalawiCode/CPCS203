(a) Complete: a class describes what an object ______ ; an interface describes what an object ______ .

(b) Java rejects class D extends B, C. Name the problem this rule avoids and explain it in one sentence.

(c) We want one array that holds an Apple, an Orange and a Chicken (all edible) but never a Tiger. Why is Object[] a poor choice, and what type should the array have?

(d) Rewrite these two interface members exactly as the compiler sees them:  double RATE = 0.15;   and   double pay();

(e) The interface NutritionInfo declares int MAX_CALORIES = 2000;. Write the expression another class uses to read this constant.

Model Answer — Q2

(a) A class = what the object IS (its identity, the is-a relationship); an interface = what the object CAN DO (a behaviour, the can-do relationship).

(b) The diamond problem: if B and C both override a method of A, then D would not know which version to inherit — the call is ambiguous.

(c) Object[] also accepts a Tiger (everything is an Object), so the compiler cannot protect us. Use an Edible[] array: only objects of classes that implement Edible can go in.

(d) public static final double RATE = 0.15;  and  public abstract double pay();

(e) NutritionInfo.MAX_CALORIES  (InterfaceName.CONSTANT_NAME)

(f) Implement all four methods, or declare the class abstract so that a concrete subclass completes the missing ones.

Q4 Output Tracing — An Interface as a Parameter Type MEDIUM CLO 10SO-a 6 marks

An online shop gives discounts. Write the exact output of Shop, one line per line.

interface Discountable {
  double RATE = 0.10;
  double discount(double amount);
}

abstract class Customer
               implements Discountable {
  private String name;
  public Customer(String name) {
    this.name = name;
  }
  public String getName() { return name; }
  @Override
  public double discount(double amount) {
    return amount * RATE;
  }
}

class Regular extends Customer {
  public Regular(String name) {
    super(name);
  }
}

class Gold extends Customer {
  public Gold(String name) {
    super(name);
  }
  @Override
  public double discount(double amount) {
    return super.discount(amount) * 2;
  }
}
class Coupon implements Discountable {
  @Override
  public double discount(double amount) {
    if (amount >= 100) return 15;
    return 0;
  }
}

public class Shop {
  public static double pay(Discountable d,
                           double amount) {
    double off = d.discount(amount);
    System.out.println("off " + off);
    return amount - off;
  }

  public static void main(String[] args) {
    System.out.println(
          pay(new Regular("Sami"), 200));
    System.out.println(
          pay(new Gold("Nora"), 200));
    System.out.println(
          pay(new Coupon(), 80));
    Discountable d = new Gold("Reem");
    System.out.println(
          d instanceof Customer);
  }
}

Regular inherits discount from Customer (the abstract class implements the interface for its subclasses), so 200 × 0.10 = 20.0. Gold overrides it: 20.0 × 2 = 40.0. Q7 Tricky Tracing — Interface Hierarchy, instanceof and Casting HARD CLO 10SO-a 8 marks

A city-guide app rates places. Write the exact output of Guide, one line per line.

interface Rateable {
  int MAX = 5;
  int rate();
}
interface Reviewable extends Rateable {
  String review();
}

abstract class Place {
  private String name;
  public Place(String name) {
    this.name = name;
  }
  public String getName() { return name; }
}

class Cafe extends Place
           implements Reviewable {
  public Cafe(String name) { super(name); }
  @Override
  public int rate() { return 4; }
  @Override
  public String review() {
    return "good coffee";
  }
}

class Museum extends Place
             implements Rateable {
  public Museum(String name) {
    super(name);
  }
  @Override
  public int rate() { return MAX; }
}

class Park extends Place {
  public Park(String name) { super(name); }
}

class BookCafe extends Cafe {
  public BookCafe(String name) {
    super(name);
  }
  @Override
  public String review() {
    return "quiet, " + super.review();
  }
}
public class Guide {
  public static void main(String[] args) {
    Place[] places = { new Cafe("Bean"),
      new Museum("Art"), new Park("Green"),
      new BookCafe("Read") };
    int total = 0;
    for (Place p : places) {
      if (p instanceof Rateable) {
        Rateable r = (Rateable) p;
        total += r.rate();
        System.out.print(p.getName() + ": "
                         + r.rate());
        if (r instanceof Reviewable) {
          Reviewable v = (Reviewable) r;
          String txt = v.review();
          System.out.print(" - " + txt);
        }
        System.out.println();
      } else {
        System.out.println(p.getName()
                           + ": not rated");
      }
    }
    int max = Rateable.MAX * places.length;
    System.out.println("Total " + total
                       + " of " + max);
  }
}
Output:
Model Answer — Q7
Bean: 4 - good coffee
Art: 5
Green: not rated
Read: 4 - quiet, good coffee
Total 13 of 20

Cafe implements Reviewable, which extends Rateable, so a Cafe is also Rateable. Museum is Rateable but not Reviewable; its MAX is the interface constant 5. Park implements nothing. BookCafe inherits rate() (4) and both interfaces from Cafe, and its overriding review() calls super.review(). Total = 4 + 5 + 4 = 13; 5 × 4 = 20. Marks: line 1 (2), line 2 (1), line 3 (1), line 4 (2), line 5 (2). Output copied from a real run.

Model Answer — Q10
public interface Rentable {
  int MAX_DAYS = 30;   // static final
  double dailyRate();  // abstract
  double cost(int days);
}

// sorting the array (uses compareTo):
java.util.Arrays.sort(fleet);

// Test: fleet = Camry 180, Yaris 120,
//               Tahoe 350
// after sorting, printing each car gives:
//   Yaris @ 120.0
//   Camry @ 180.0
//   Tahoe @ 350.0
// fleet[0].cost(3)  -> 360.0
// fleet[0].cost(45) -> 3600.0  (30 days)
public class Car
    implements Rentable, Comparable<Car> {
  private String model;
  private double rate;

  public Car(String model, double rate) {
    this.model = model;
    this.rate = rate;
  }
  @Override
  public double dailyRate() {
    return rate;
  }
  @Override
  public double cost(int days) {
    if (days > MAX_DAYS)
      days = MAX_DAYS;
    return days * dailyRate();
  }
  @Override
  public int compareTo(Car other) {
    if (rate > other.rate) return 1;
    else if (rate < other.rate) return -1;
    else return 0;
  }
  @Override
  public String toString() {
    return model + " @ " + rate;
  }
}

Rubric: interface with the constant and two method headers, no bodies (2) · implements Rentable, Comparable<Car> + private fields + constructor (1) · dailyRate and cost with the 30-day cap, both public (2) · compareTo(Car other) correct (2) · toString and Arrays.sort(fleet) (1). Missing public on an implemented method loses that method’s mark (weaker access). Code compiled and run with the test shown.

public interface Fragile {
  double EXTRA = 5.0;
  String handling();
}

public abstract class Item {
  private String name;
  private double weight;

  public Item(String name, double weight) {
    this.name = name;
    this.weight = weight;
  }
  public String getName() { return name; }
  public double getWeight() {
    return weight;
  }
  public abstract double shippingCost();
}
public class Glassware extends Item
                       implements Fragile {
  public Glassware(String name, double w) {
    super(name, w);
  }
  @Override
  public double shippingCost() {
    return 2 * getWeight() + EXTRA;
  }
  @Override
  public String handling() {
    return "Wrap in bubble film";
  }
}

// (c)
double total = 0;
for (Item it : box) {
  total += it.shippingCost();
  if (it instanceof Fragile) {
    Fragile f = (Fragile) it;
    System.out.println(it.getName() + ": "
                       + f.handling());
  }
}
System.out.println("Total shipping: "
                   + total + " SAR");

(b) Fragile with constant and abstract method (1); Item abstract with private fields, constructor and abstract shippingCost() (1); Glassware extends Item implements Fragile calling super(name, w) (1); both methods public and using getWeight() + EXTRA (1) — weight is private in Item.
