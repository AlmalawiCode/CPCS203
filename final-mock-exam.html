Model Answer — II.2
public static String makeUsername(String fullName, int year) {
    String name = fullName.trim();                       // 0.25
    int firstSpace = name.indexOf(' ');
    if (firstSpace == -1) {                              // 0.5
        return "INVALID";
    }
    int lastSpace = name.lastIndexOf(' ');
    StringBuilder sb = new StringBuilder();
    sb.append(Character.toLowerCase(name.charAt(0)));    // 0.5
    sb.append(name.substring(lastSpace + 1).toLowerCase()); // 0.5
    sb.append(year % 100);                               // 0.5
    return sb.toString();                                // 0.25
}
// also accepted: split
public static String makeUsername2(String fullName, int year) {
    String[] words = fullName.trim().split(" ");
    if (words.length < 2) {
        return "INVALID";
    }
    StringBuilder sb = new StringBuilder();
    sb.append(words[0].toLowerCase().charAt(0));
    sb.append(words[words.length - 1].toLowerCase());
    sb.append(String.valueOf(year).substring(2));
    return sb.toString();
}

Real run of both versions: salghamdi26, osaleh25, INVALID.

class Truck extends Vehicle implements Insurable {
    private double loadTons;

    public Truck(String plate, double dailyRate, double loadTons) {
        super(plate, dailyRate);

    for (Vehicle v : fleet) {
        if (v.getPlate().equals(plate)) {
            return v.rentalCost(days);
        }
    }
    throw new RentalException("No vehicle " + plate);
}

Header with throws RentalException (0.25) · days check + throw new RentalException(...) (0.5) · loop over the ArrayList comparing plates with equals (0.5) · return v.rentalCost(days) — dynamic binding picks the Car or Truck version (0.5) · throw “No vehicle” after the loop (0.25). An index loop with fleet.get(i) and fleet.size() is equally correct.

public double totalInsurance(int days) {
