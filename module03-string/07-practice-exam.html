Q5 Rewrite for Efficiency — Concatenation in a Loop MEDIUM CLO 1SO-a 6 marks

Because the String class is immutable, the loop below takes a very long time and wastes a great deal of memory. Rewrite it so that it produces exactly the same printed result but runs far faster, then explain in one sentence why your version is better.

String report = "";
for (int i = 0; i < 100000; i++) {
    report = report + "line " + i + "\n";
}
System.out.println(report.length());
Your rewritten code:
Why it is better:
Model Answer — Q5
StringBuilder report = new StringBuilder();
for (int i = 0; i < 100000; i++) {
    report.append("line ").append(i).append("\n");
}
System.out.println(report.length());

Why: a StringBuilder is mutable. It appends into one growing internal character array, whereas the original loop builds a brand-new String object and copies every character already accumulated on each of the 100,000 iterations.

Rubric: StringBuilder declared and constructed 2 · append used inside the loop 2 · explanation naming mutability or "a new object per iteration" 2. StringBuffer is equally acceptable and should receive full marks.

Q8 Write a Method — Initials of a Full Name HARD CLO 1SO-a 8 marks

Write a Java method that builds the initials of a full name. The method should accept a single String as input parameter and return a String. Every word of the name contributes its first letter in upper case, and each letter is followed by a dot.

For example, if the passed String is "ali fahad omar", the value "A.F.O." should be returned. Also, indicate how to invoke the method using a given String name from the main method.

Write your complete method, then the call from main:
Model Answer — Q8
public static String initials(String name) {
    StringBuilder result = new StringBuilder();
    String[] words = name.trim().split(" +");

    for (int i = 0; i < words.length; i++) {
        result.append(Character.toUpperCase(words[i].charAt(0)));
        result.append(".");
    }
    return result.toString();
}

// invocation from main:
String fullName = "ali fahad omar";
System.out.println(initials(fullName));      // prints A.F.O.

Equally acceptable without split: walk the String with charAt, take index 0 and every character that follows a space.

Rubric: correct method signature and return type 1.5 · separating the words, by split or by scanning for spaces 2 · taking the first character of each word 1.5 · converting it to upper case 1 · adding the dot separator 1 · returning the String and calling it correctly from main 1. Do not deduct marks for basic syntax errors.

            System.out.println("Length is: " + s.length());
        ……………………………………                    // (4)

    }

The character is: v

An exception occurs

Model Answer — Q9
static void show(String s, int index) {

    try {                                                    // (1)
        System.out.println("The character is: " + s.charAt(index));
    } catch (StringIndexOutOfBoundsException e) {            // (2)
        System.out.println("An exception occurs");
    } finally {                                              // (3)
        System.out.println("Length is: " + s.length());
    }                                                        // (4)
}

2 marks per blank. In (2) accept IndexOutOfBoundsException or Exception for full marks, since both catch the thrown object. The point of the question is (3): the finally block runs on both calls, which is why Length is: 4 appears twice, once after a success and once after a failure.

Q10 Write a Method — Palindrome Using StringBuilder HARD CLO 1SO-a 8 marks

Write the method

public static boolean isPalindrome(String s)

which returns true when s reads the same forwards and backwards, ignoring upper and lower case and ignoring every character that is not a letter. You must use a StringBuilder. Also, indicate how to invoke the method from the main method.

CallReturns
isPalindrome("Never odd or even")true
isPalindrome("KAU, UAK!")true
isPalindrome("Jeddah")false
Write your complete method, then the call from main:
Model Answer — Q10
public static boolean isPalindrome(String s) {

    StringBuilder clean = new StringBuilder();

    for (int i = 0; i < s.length(); i++) {
        char ch = s.charAt(i);
        if (Character.isLetter(ch))
            clean.append(Character.toLowerCase(ch));
    }

    String forward  = clean.toString();       // taken BEFORE the reverse
    String backward = clean.reverse().toString();

    return forward.equals(backward);
}

// invocation from main:
System.out.println(isPalindrome("Never odd or even"));    // true

Rubric: signature and return type 1 · loop over charAt 1.5 · Character.isLetter filter 1.5 · Character.toLowerCase 1 · appending into the StringBuilder 1 · reverse() plus equals 1.5 · call from main 0.5.

Note the subtlety worth discussing in class: reverse() changes clean itself, so forward must be extracted first. It survives the reversal only because the String it points at is immutable. A solution that compares clean.toString() with clean.reverse().toString() inside a single expression is fragile and loses 1.5 marks.
