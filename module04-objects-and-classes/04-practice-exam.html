(b) In main, create an object myAcc with id 2025 and balance 500.0, deposit 250.0, then print its balance and the total number of accounts. [2 marks]

Model Answer — Q8
public class BankAccount {
    private int id;
    private double balance;
    private static int totalAccounts = 0;

    public BankAccount() {
        this(1000, 0.0);
    }
    public BankAccount(int id, double balance) {
        this.id = id;
        this.balance = balance;
        totalAccounts++;
    }
    public int getId() {
        return id;
    }
    public double getBalance() {
        return balance;
    }

    public void deposit(double amount) {
        balance = balance + amount;
    }
    public boolean withdraw(double amount) {
        if (amount <= balance) {
            balance = balance - amount;
            return true;
        }
        return false;
    }
    public static int getTotalAccounts() {
        return totalAccounts;
    }
}

// (b) in main:
BankAccount myAcc = new BankAccount(2025, 500.0);
myAcc.deposit(250.0);
System.out.println(myAcc.getBalance());       // 750.0
System.out.println(BankAccount.getTotalAccounts());  // 1

(a) private fields with - 1 · underlined field and method made static 1 · no-arg constructor using this(1000, 0.0) 1 · two-arg constructor with this. and the counter 1 · getters and deposit 1 · withdraw with the condition and both returns 1. (b) object created 1 · deposit and both prints 1. Watch for totalAccounts++ written in both constructors: since the no-arg constructor calls the other one, every default account would be counted twice — deduct 0.5.

The class Product on the left is already written.

Write a Java method that finds the cheapest product in an array. The method should accept an array of Product as input parameter and return a Product. The array may be only partly filled: some elements may be null. If the array holds no products, return null.

For example, with the array below the method returns the Eraser object. Also, indicate how to invoke the method from the main method and print the name of the cheapest product.

Product[] items = new Product[5];
items[0] = new Product("Pen", 4.5);
items[1] = new Product("Notebook", 12.0);
items[3] = new Product("Eraser", 2.0);   // items[2], items[4] are null

Model Answer — Q10
public static Product cheapest(Product[] items) {
    Product best = null;
    for (int i = 0; i < items.length; i++) {
        if (items[i] != null) {
            if (best == null || items[i].getPrice() < best.getPrice())
                best = items[i];
        }
    }
    return best;
}

// invocation from main:
Product p = cheapest(items);
if (p != null)
    System.out.println(p.getName());          // prints Eraser

Rubric: signature with Product[] parameter and Product return type 1.5 · loop over the array 1 · skipping null elements 2 · comparing prices through getPrice() (not .price, which is private) 1.5 · keeping and returning the object, not just the price 1 · call from main 1.

The point of the question: best = items[0] as a starting value is fragile — if slot 0 is empty, the first best.getPrice() throws NullPointerException. Deduct 1 mark when nulls are not handled.

Q11 Apply — Build the Book Class Step by Step HARD CLO 3SO-c 8 marks · 1 per step

A bookshop wants to describe the properties and behaviours of its books using a Java class. Follow the steps below.

  1. Create a class named Book with three variables that can only be accessed within the class: isbn and title of type String, and price of type double.
  2. Add a variable count, shared by all books, that counts how many Book objects have been created.
  3. Declare a three-parameter constructor that initialises isbn, title and price and updates count.
  4. Declare a default constructor that invokes the three-parameter constructor with "000", "Untitled" and 0.0.
  5. Write getters for title and price, and a setter for price that ignores negative values.
  6. Write a method getCount() that can be called using the class name.
  7. In the main method of a class BookStore, create an array of size three that can only hold Book objects; fill it with two books made by the three-parameter constructor and one made by the default constructor.
  8. Iterate over the array: raise every price by 10% using the setter and print each title and new price. Finally print the value of count.
Model Answer — Q11
public class Book {
    private String isbn;                 // Step 1
    private String title;
    private double price;
    private static int count = 0;        // Step 2

    public Book(String isbn, String title,
                double price) {          // Step 3
        this.isbn = isbn;
        this.title = title;
        this.price = price;
        count++;
    }
    public Book() {                      // Step 4
        this("000", "Untitled", 0.0);
    }
    public String getTitle() {           // Step 5
        return title;
    }
    public double getPrice() {
        return price;
    }
    public void setPrice(double price) {
        if (price >= 0)
            this.price = price;
    }
    public static int getCount() {       // Step 6
        return count;
    }
}

public class BookStore {
  public static void main(String[] args) {
    Book[] books = new Book[3];              // Step 7
    books[0] = new Book("111", "Java Basics", 80.0);
    books[1] = new Book("222", "Data Structures", 120.0);
    books[2] = new Book();

    for (int i = 0; i < books.length; i++) { // Step 8
      books[i].setPrice(books[i].getPrice() * 1.10);
      System.out.println(books[i].getTitle()
                         + " " + books[i].getPrice());
    }
    System.out.println("Books created: "
                       + Book.getCount());
  }
}

/* Output:
Java Basics 88.0
Data Structures 132.0
Untitled 0.0
Books created: 3          */

1 mark per step. Step 2 needs static; Step 4 needs this(...) as the first statement, and if count++ also appears in the default constructor the count becomes 4 — lose the Step 4 mark. Step 7: new Book[3] creates no Book objects; three new Book(...) calls are still needed, otherwise Step 8 throws NullPointerException. Step 8: the 10% rise must go through the setter; books[i].price = … does not compile from BookStore.
