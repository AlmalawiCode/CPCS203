1 Case Study — java.lang.Number (Abstract in the Real Java API)

Everything we studied in this module exists right inside Java's standard library. The perfect example: java.lang.Number.

📌 What Is java.lang.Number?

Number is the abstract superclass of all numeric wrapper classes in Java. It is declared as:

public abstract class Number extends Object

It has abstract methods that every numeric subclass must implement. You cannot do new Number() — it is abstract!

📄 java.lang.Number — Simplified Declaration ▼
// java.lang.Number — as declared in Java's source code (simplified) public abstract class Number extends Object { // Abstract methods — every subclass MUST implement these public abstract int intValue(); public abstract long longValue(); public abstract float floatValue(); public abstract double doubleValue(); } // Integer — one concrete subclass public final class Integer extends Number { private final int value; @Override public int intValue() { return value; } @Override public long longValue() { return (long) value; } @Override public float floatValue() { return (float) value; } @Override public double doubleValue() { return (double) value; } // ... many more methods }
📌 Why valueOf instead of new Integer(...)?

The constructors new Integer(42), new Double(3.14), … still compile but are deprecated (javac prints warnings). Use Integer.valueOf(42) or simply let Java autobox: Number n = 42; — exactly what LargestNumbers does.

Polymorphism Using Number as a Data Type

// 1. Polymorphic VARIABLE ────────────────────────────────────────── Number n1 = Integer.valueOf(42); // Integer IS-A Number ✓ Number n2 = Double.valueOf(3.14); // Double IS-A Number ✓ Number n3 = Float.valueOf(2.5f); // Float IS-A Number ✓ Number n4 = 100L; // autoboxing: Long IS-A Number ✓ // 2. Polymorphic ARRAY ───────────────────────────────────────────── Number[] numbers = { Integer.valueOf(10), Double.valueOf(3.14), Float.valueOf(2.5f), Long.valueOf(100L), Short.valueOf((short) 5) }; for (Number num : numbers) { System.out.printf("int=%-6d double=%.2f%n", num.intValue(), num.doubleValue()); } // 3. Polymorphic METHOD ──────────────────────────────────────────── public static void showNumber(Number n) { // accepts ANY Number subclass System.out.println("Value as double: " + n.doubleValue()); } showNumber(Integer.valueOf(7)); showNumber(new BigInteger("999999999999999999"));

💡 The Lesson from Number

Java's own designers used the abstract class pattern for Number for exactly the same reasons we use it for Shape: "Number" is too general to have its own object, but it provides a shared interface and IS-A relationship for all numeric types — enabling polymorphism across the entire numeric hierarchy.

2 LargestNumbers — Finding the Largest Number in a List

Because Number is the common (abstract) superclass of all numeric wrappers, one list can hold integers and doubles together, and one method can find the largest of them.

📄 LargestNumbers.java Slide 23 ▼
import java.util.ArrayList; public class LargestNumbers { public static void main(String[] args) { ArrayList<Number> list = new ArrayList<>(); list.add(45); // autoboxed to Integer list.add(3445.53); // autoboxed to Double list.add(33.9); // Double list.add(46); // Integer System.out.println("The largest number is " + getLargestNumber(list)); } public static Number getLargestNumber(ArrayList<Number> list) { if (list == null || list.size() == 0) return null; Number number = list.get(0); for (int i = 1; i < list.size(); i++) if (number.doubleValue() < list.get(i).doubleValue()) number = list.get(i); return number; } }
Output — LargestNumbers.java (Run)
The largest number is 3445.53

❓ Questions on LargestNumbers Slides 22–23

Q1. How can list.add(45) and list.add(3445.53) both go into an ArrayList<Number>?

Autoboxing + polymorphism. 45 is boxed to an Integer and 3445.53 to a Double. Both are subclasses of Number (an Integer is a Number), so both can be stored in a list whose element type is the abstract class Number.

Q2. Why does getLargestNumber compare with doubleValue() instead of number < list.get(i)?

< does not work on objects (a Number reference is not a primitive), and a general Number has no "real" value we can read directly. But every Number must implement the abstract method doubleValue(), so calling it is safe for any element. Dynamic binding runs Integer.doubleValue() or Double.doubleValue() as needed, and the comparison is done on double values.

Q3. What is printed, and what is the type of the object returned?

The largest number is 3445.53. The method's return type is Number, but the object returned is the Double 3445.53 (the element itself, not a copy), and string concatenation calls its toString().

Q4. What does getLargestNumber return for an empty list? And what if we also add a BigInteger?

For null or an empty list it returns null (the first if). A BigInteger or BigDecimal is also a Number, so it can be added and compared with no change to the method. Verified:
