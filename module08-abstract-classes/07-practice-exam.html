Q2 Short Answers — The Basics of Abstract Classes EASY CLO 10SO-a 6 marks · 1 each

(a) We never create a plain Shape object, only circles and rectangles. Give the two reasons why we still keep the class Shape.

(b) new Student() is illegal because Student is abstract. Then why can Student have constructors, and who calls them?

(c) What is the difference between public abstract void draw(int size); and public void draw(int size) { }?

(d) A subclass inherits two abstract methods but implements only one of them. What must be true about this subclass?

(e) Is abstract class Animal { public void eat() { } } legal even though it has no abstract method? What is the effect of the word abstract here?

(f) “A subclass can be abstract even if its superclass is concrete.” Give one example from the Java library.

Model Answer — Q2

(a) Inheritance — the common fields and methods (e.g. color, getColor()) are written once; polymorphism — one Shape variable, array or parameter can refer to every kind of shape (an IS-A relationship).

(b) Its constructors initialise the fields of the abstract class (e.g. login, name) for every subclass object. They are called by the constructors of the subclasses, through super(…) — written by us or inserted by the compiler.

(c) The first is abstract: no body (a semicolon), the class must be abstract, and every concrete subclass is forced to implement it. The second is a normal method with an empty body: it does nothing and subclasses are not forced to override it.

(d) The subclass must also be declared abstract (it is still incomplete), so it cannot be instantiated.

(e) Legal. The class simply cannot be instantiated with new; it is used only as a base class for subclasses.

(f) Object is concrete, but its subclass Number is abstract (also our own Shape/GeometricObject, which extend Object).

1 mark each; (a) and (c) need both parts for the mark.

Q8 Case Study — The Abstract Number Class MEDIUM CLO 10SO-a 6 marks

public class Prices {

Model Answer — Q10
public abstract class Subscription {
    private String name;
    private int months;

    public Subscription(String name, int months) {
        this.name = name;
        this.months = months;
    }
    public String getName() { return name; }
    public int getMonths()  { return months; }

    public abstract double monthlyFee();   // no body

    public double totalCost() {
        return monthlyFee() * months;      // dynamic binding
    }
    @Override
    public String toString() {
        return name + ": " + months
               + " months, total " + totalCost();
    }
}
public class StreamingPlan extends Subscription {
    private int screens;

    public StreamingPlan(String name, int months,
                         int screens) {
        super(name, months);           // first statement
        this.screens = screens;
    }
    public int getScreens() { return screens; }

    @Override
    public double monthlyFee() {
        return 15.0 + 10.0 * screens;
    }
}

// Subscription s = new StreamingPlan("Family", 6, 2);
// System.out.println(s);   prints
// Family: 6 months, total 210.0

Model Answer — Q11

public abstract class Employee {
    private String name;

    public Employee(String name) {
        this.name = name;
    }
    public String getName() { return name; }

    public abstract double monthlyPay();

    @Override
    public String toString() {
        return name + " earns " + monthlyPay();
    }
}

public class SalariedEmployee extends Employee {
    private double salary;

    public SalariedEmployee(String name,
                            double salary) {
        super(name);
        this.salary = salary;
    }
    @Override
    public double monthlyPay() {
        return salary;
    }
}
public class HourlyEmployee extends Employee {
    private int hours;
    private double rate;

    public HourlyEmployee(String name, int hours,
                          double rate) {
        super(name);
        this.hours = hours;
        this.rate = rate;
    }
    @Override
    public double monthlyPay() {
        return hours * rate;
    }
}

// (c)
public static double totalPayroll(Employee[] staff) {
    double total = 0;
    for (Employee e : staff)
        total += e.monthlyPay();   // dynamic binding
    return total;
}
