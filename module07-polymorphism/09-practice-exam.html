Q2 Short Answers — The Words of Polymorphism EASY CLO 8SO-a 6 marks · 1 each

(a) What do the Greek parts poly and morph mean? Complete: “Polymorphism means that a variable of a ________ can refer to a ________ object.”

(b) For Object o = new Circle(3); give the declared type and the actual type of o. Which of the two decides which toString() runs?

(c) For Animal a = new Cat(); a.sound(); explain method matching and method binding: who does each, and when?

(d) Which one is automatic, upcasting or downcasting? Which one needs an explicit cast and may fail at run time — with which exception?

(e) Write the equals method exactly as it is written in the class Object.

(f) After Circle c1 = new Circle(1); Circle c2 = c1; c2.setRadius(5); what does c1.getRadius() return? What are c1 and c2 called?

Model Answer — Q2

(a) poly = many, morph = shapes / forms (“having many forms”). A variable of a supertype can refer to a subtype object.

(b) Declared type Object; actual type Circle. The actual type decides which toString() runs (dynamic binding).

(c) Matching: the compiler, at compile time, uses the declared type (Animal) to find a method with matching parameter types, number and order. Binding: the JVM, at run time, picks the implementation from the actual type (Cat).

(d) Upcasting (subclass object → superclass variable) is automatic. Downcasting needs (SubclassName) and may throw a ClassCastException.

(e) public boolean equals(Object obj) { return this == obj; } — it only checks whether the two references point to the same object.

(f) 5.0 — c1 and c2 are aliases: two references to the same object.

Model Answer — Q10
public class SavingsAccount extends Account {
    private double rate;

    public SavingsAccount(String id, double balance, double rate) {
        super(id, balance);                  // id and balance are private in Account
        this.rate = rate;
    }
    public double getRate() {
        return rate;
    }
    public double interest() {
        return getBalance() * rate / 100;
    }
    @Override
    public double monthlyFee() {
        if (getBalance() >= 5000)
            return 0.0;
        else
            return super.monthlyFee();       // reuse Account's fee
    }
    @Override
    public String toString() {
        return "Savings " + super.toString() + ", rate " + rate + "%";
    }
    @Override
    public boolean equals(Object o) {        // parameter type Object = override
        if (o instanceof SavingsAccount) {
            SavingsAccount other = (SavingsAccount) o;   // downcast
            return getId().equals(other.getId()) && rate == other.rate;
        }
        else
            return false;
    }
}

(d) A student says: “Let’s add getRadius() to Shape, returning 0, so we never need to cast.” Is this good design? Explain using the design rule from the lecture. (2 marks)

Model Answer — Q11
public class ShapeTools {
    // (a)
    public static double totalArea(ArrayList<Shape> list) {
        double total = 0;
        for (Shape s : list)
            total += s.getArea();            // dynamic binding: Circle's or Rectangle's getArea
        return total;
    }

    // (b)
    public static double largestRadius(ArrayList<Shape> list) {
        double largest = 0;
        for (Shape s : list) {
            if (s instanceof Circle) {       // check first ...
                double r = ((Circle) s).getRadius();   // ... then downcast
                if (r > largest)
                    largest = r;
            }
        }
        return largest;
    }

    public static void main(String[] args) {
        ArrayList<Shape> shapes = new ArrayList<>();
        shapes.add(new Circle(1.0, "red"));
        shapes.add(new Rectangle(2.0, 3.0, "green"));
        shapes.add(new Circle(2.0, "blue"));
        System.out.println("Total area: " + totalArea(shapes));        // Total area: 21.707963267948966
        System.out.println("Largest radius: " + largestRadius(shapes)); // Largest radius: 2.0
    }
}

(c) Dynamic binding (polymorphism): the JVM chooses the method at run time from the actual type of each object.

(d) No. Only put a method in the superclass if it is naturally shared by all (or most) subclasses. A rectangle has no radius, so getRadius() in Shape would be a forced, meaningless method (like addHours() in StaffMember). Do not push methods up just to reach 100% polymorphism; use instanceof + downcasting for subclass-only methods.

(a) loop over the list (1), s.getArea() without casting (1). (b) instanceof check (1), downcast to reach getRadius() (1), correct maximum and 0 when there is no circle (1). (c) 1 mark. (d) verdict (1), reason based on the design rule (1). The code was run with Java 21 and prints the values in the comments.
