1 Summary — What You Learned Today

🇬🇷
Etymology
Poly (many) + morphe (form). From Greek. Means "many forms."
🧬
Biology Analogy
Group creatures by common type. One treatment for the whole group.
🔑
The Condition
Objects MUST be related by inheritance (IS-A relationship).
🔄
3 Forms
Polymorphic variable, polymorphic array, polymorphic method.
🔍
What You See
Polymorphic ref only sees superclass (shared) methods.
☕
The Cup
General cup = polymorphic. Arabic coffee cup = non-polymorphic.
⬆⬇
Casting
Upcasting is automatic. Downcasting needs explicit cast + instanceof.
🌟
Dynamic Binding
Java picks the method version at RUNTIME based on actual object type.
⚖
Good Design
Only add reasonable, shared behaviors to the superclass. Don't force 100%.
📌
ArrayList
A dynamic array built on a fixed array inside. Stores Object → polymorphic. Casting required until Generics.
👤
Array of Objects
Arrays can hold objects — but size is fixed. You must copy manually to resize.
🔄
Dynamic Array
ArrayList hides a fixed array inside. Full? Auto-expand 1.5× and copy. Stores Object → polymorphic!

Lesson 2 — Declared vs Actual Type Slides 7–18

Prove it — test yourself
True or false? (a) Every circle is a geometric object. (b) Every geometric object is a circle.
Show answer
(a) True. (b) False. Every instance of a subclass is also an instance of its superclass, but not vice versa.
Review: Lesson 2 →
Prove it — test yourself
Which line compiles? (a) Animal animal = new Cat(); (b) Cat cat = new Animal();
Show answer
(a) compiles — a cat is an animal, so an Animal reference can point to a Cat object. (b) compile error — an animal is not necessarily a cat.
Review: Lesson 2 →
Prove it — test yourself
Object o = new GeometricObject(); — what is o’s declared type? Its actual type? Besides a reference to an object, what else can a reference variable hold?
Show answer
Declared type: Object. Actual type: GeometricObject (the class of the object it refers to). It can also hold null.
Review: Lesson 2 →
Prove it — test yourself
Animal animal = new Cat(); animal.sound(); animal = new Duck(); animal.sound(); — which two sound() methods run? Define “polymorphic reference”.
Show answer
First Cat’s sound(), then Duck’s: the type of the object being referenced (actual), not the reference (declared) type, decides. A polymorphic reference is a variable that can refer to different types of objects at different points in time.
Review: Lesson 2 →
Prove it — test yourself
Mammal has a method run() and Horse overrides it. Mammal animal = new Horse(); animal.run(); — which run version is invoked?
Show answer
Horse’s run() — the actual object is a Horse.
Review: Lesson 2 →
Prove it — test yourself
public static void displayObject(Shape object) prints "Color is " + object.getColor(). Is displayObject(new Circle(1, "red", false)) legal? What do this call and displayObject(new Rectangle(1, 1, "black", true)) print for the colour?
Show answer
Yes — an object of a subclass can be used wherever its superclass object is used. They print Color is red and Color is black (each line also starts with “Created on <date>”).
Review: Lesson 2 →
Prove it — test yourself
Why do m(new GraduateStudent()), m(new Student()), m(new Person()) and m(new Object()) all compile? What assignment happens behind each call?
Show answer
Every class IS-A Object, so each call does Object x = new GraduateStudent(); (or Student, Person, Object). This feature is known as polymorphism.
Review: Lesson 2 →
Prove it — test yourself
Complete: “Polymorphism allows methods to be used ______ for a wide range of object arguments. This is known as ______.”
Show answer
…used generically … known as generic programming. Example: one method m(Object x) works for every class.
Review: Lesson 2 →

Lesson 3 — Dynamic Binding Slides 19–35

Prove it — test yourself
With m(Object x) { System.out.println(x.toString()); }, what do m(new GraduateStudent()); m(new Student()); m(new Person()); m(new Object()); print? (Student overrides toString; GraduateStudent does not.)
Show answer
Student, Student, Person, java.lang.Object@… (the hex number differs from run to run, e.g. java.lang.Object@7852e922). GraduateStudent inherits Student’s toString. Which implementation is used is decided dynamically by the JVM at runtime — dynamic binding.
Review: Lesson 3 →
Prove it — test yourself
Object o = new GeometricObject(); System.out.println(o.toString()); — toString is defined in Object and overridden in GeometricObject. Which one is invoked by o?
Show answer
GeometricObject’s toString() — the method is implemented in several classes along the inheritance chain and the JVM picks it at runtime from the actual type.
Review: Lesson 3 →
Prove it — test yourself
C1 extends C2, C2 extends C3, C3 extends Cn. Only Cn and C2 define m(). C3 o = new C1(); o.m(); — does it compile, and which m runs?
Show answer
It compiles (C3 inherits m from Cn). It runs C2’s m(): the JVM searches C1, C2, …, Cn in this order and the first-found implementation is invoked (tested in Java: prints C2’s message).
Review: Lesson 3 →
Prove it — test yourself
Same chain, but now Cn has no m(); C3, C2, C1 define it. Cn o = new C2(); o.m(); — result?
Show answer
Compile error — the declared type (Cn) should have the invoked method. The compiler only looks at the declared type.
Review: Lesson 3 →
Prove it — test yourself
For Animal animal = new Cat(); animal.sound();, who checks what, and when?
Show answer
Compile time: the compiler matches the signature using the declared type (Animal), by parameter type, number of parameters and order. Run time: the JVM dynamically binds the implementation from the actual type (Cat).
Review: Lesson 3 →
Prove it — test yourself
Integer[] list1, Double[] list2 and int[] list3 are each passed to printArray(Object[] list). Which call is wrong and why?
Show answer
printArray(list3) — int[] cannot be passed to Object[] (javac: “incompatible types: int[] cannot be converted to Object[]”). int is a primitive, not an object; Integer[] and Double[] are fine.
Review: Lesson 3 →

Which classes extend StaffMember, and which extend Employee?

In amount = staffList[count].pay(); the array type is StaffMember[]. Which pay() runs, and what is printed for a Volunteer?

The pay() of the actual object (Executive, Employee, Hourly or Volunteer) — dynamic binding. A Volunteer returns 0.0, so Thanks! is printed.

Why does staffList[3].addHours(hour); not compile? Give the fixed line.
Show answer
staffList is StaffMember[] and StaffMember has no addHours; the compiler is not clever enough to know staffList[3] is an Hourly. Fix: ((Hourly) staffList[3]).addHours(hour); (and ((Executive) staffList[0]).awardBonus(bonus);).

Lesson 5 — Casting & instanceof Slides 49–64

Prove it — test yourself
double d; int i; Which compile: (a) d = 5; (b) i = 3.5; (c) i = (int) 3.5;? What is i after (c)?
Show answer
(a) yes — widening is legal. (b) no — narrowing is illegal unless you cast. (c) yes; i = 3 — everything after the decimal point is lost.
Review: Lesson 5 →
Prove it — test yourself
Why does Object x = new Student(); work but Student x = new Object(); does not?
Show answer
A Student object is always an instance of Object (implicit casting is legal). An Object is not necessarily an instance of Student.
Review: Lesson 5 →
Prove it — test yourself
Object x = new Student(); Student a = x; — does it compile? Fix it.
Show answer
No. Even though you can see x is really a Student, the compiler is not so clever to know it. Fix: Student a = (Student) x;
Review: Lesson 5 →
Prove it — test yourself
Fruit fruit = new Apple(); then (a) Apple x = fruit; (b) Apple x = (Apple) fruit; (c) Orange x = (Orange) fruit;
Show answer
(a) compile error — a fruit is not necessarily an apple. (b) OK — explicit casting. (c) compiles, but ClassCastException at runtime — the object is an Apple, not an Orange (tested in Java).
Review: Lesson 5 →
Prove it — test yourself
Which one is always possible? Which one needs the (SubclassName) notation, and may not always succeed?
Show answer
Upcasting (subclass → superclass variable) is always possible. Downcasting (superclass → subclass variable) needs explicit casting, e.g. (Student), to confirm your intention to the compiler — and it may fail at runtime.
Review: Lesson 5 →
Prove it — test yourself
Object myObject = new Circle(); — why is myObject.getDiameter() a compile error? Write the safe call.
Show answer
The declared type Object has no getDiameter (the declared type decides which method to match). Safe: if (myObject instanceof Circle) System.out.println(((Circle) myObject).getDiameter());
Review: Lesson 5 →
Prove it — test yourself
We do not know which index holds an Hourly. Rewrite addHours(int hour) so it works for every Hourly in staffList.
Show answer
for (StaffMember s : staffList) if (s instanceof Hourly) ((Hourly) s).addHours(hour); — and the same pattern with Executive for awardBonus.
Review: Lesson 5 →
Prove it — test yourself
Object object1 = new Circle(1); Object object2 = new Rectangle(1, 1); are passed to displayObject, which prints the diameter of a circle or the area of a rectangle. Output?
Show answer
The circle diameter is 2.0 and The rectangle area is 1.0 (tested in Java).
Review: Lesson 5 →
Prove it — test yourself
String s1 = "Cat"; String s2 = "Cat"; String s3 = new String("Cat"); — values of s1 == s2, s1 == s3, s1.equals(s3)?
Show answer
true, false, true (tested). Literals share one object in the String pool; new String makes a new object on the heap; equals compares contents.
Review: Lesson 5 →

Lesson 6 — == vs equals() & Aliases Slides 65–81

Prove it — test yourself
(a) Thing thing1 = new Thing(); Thing thing2 = new Thing(); (b) Thing thing3 = new Thing(); Thing thing4 = thing3; Are they equal?
Show answer
(a) That’s up to the programmer (how equals is written). (b) Yes — they are the same Thing.
Review: Lesson 6 →
Prove it — test yourself
(a) int x = 9, y = 9; x == y (b) Integer x = new Integer(9); Integer y = 9; x == y (c) Integer x = 9; Integer y = 9; x == y
Show answer
(a) true — primitives can always be tested with ==. (b) false — for objects, == tests whether they are the same object. (c) true — both refer to the same cached object (like the String pool). Two Integers or Strings may or may not be ==!
Review: Lesson 6 →
Prove it — test yourself
Integer x1 = new Integer(9); String x2 = new String("abc"); Integer y1 = 9, z1 = 9; String y2 = "abc", z2 = "abc"; then print(x1==y1); print(x2==y2); print(y1==z1); print(y2==z2);
Show answer
false false true true. (It uses print, so Java really prints falsefalsetruetrue on one line; javac also warns that new Integer is deprecated.)
Review: Lesson 6 →
Prove it — test yourself
Write Object’s equals method. What does it check?
Show answer
public boolean equals(Object obj) { return this == obj; } — it checks whether two reference variables point to the same object.
Review: Lesson 6 →
Prove it — test yourself
Name two Java API classes that override equals. What should you do in your own class?
Show answer
java.lang.String and java.util.Date compare contents. In a custom class, override equals to test whether two distinct objects have the same content.
Review: Lesson 6 →
Prove it — test yourself
int[] a1 = {1,2,3}; int[] a2 = {1,2,3}; — values of a1 == a2, a1.equals(a2), java.util.Arrays.equals(a1, a2)?
Show answer
false, false, true (tested). Morals: never use == for Strings, arrays or other objects; use equals for Strings and Arrays.equals(a1, a2) for arrays.
Review: Lesson 6 →
Prove it — test yourself
Write equals for Circle so two circles with the same radius are equal.
Show answer
public boolean equals(Object o) { if (o instanceof Circle) return radius == ((Circle) o).radius; else return false; }
Review: Lesson 6 →
Prove it — test yourself
Object circle1 = new Circle(); Object circle2 = new Circle(); System.out.println(circle1.equals(circle2)); — output with (a) equals(Circle circle) and (b) equals(Object o) in Circle?
Show answer
(a) false — it is an overload; the declared type is Object, so equals(Object) from Object (==) is matched and run. (b) true — it overrides; dynamic binding runs Circle’s version (both tested).
Review: Lesson 6 →
Prove it — test yourself
When do you use each? Which one is “stronger”?
Show answer
==: compare primitive values, or check two references point to the same object. equals: test whether two objects have the same contents (if the class overrides it). == is stronger: same object ⇒ equal contents, not the reverse.
Review: Lesson 6 →
Prove it — test yourself
Circle c1 = new Circle(1); Circle c2 = c1; c2.setRadius(5); — what is c1.getRadius()? What are c1 and c2 called?
Show answer
5.0 — c1 and c2 are aliases: two references to the same object, so changing it through one changes it for all. (This doesn’t happen with Strings — they cannot be changed; “changing” one makes a new object.)
Review: Lesson 6 →

Prove it — test yourself
Student[] array = new Student[100]; — what if the number of students increases? What if you don’t know the size?

The array’s size is fixed once created. More students → copy the array to a bigger one. Unknown size → use the ArrayList class.

list = [A, B, C]. After list.add("D"); list.add(1, "X"); what is list? What does list.set(0, "Z") return, and what is list then?

[A, X, B, C, D]; set returns A (the old element) and list becomes [Z, X, B, C, D] (tested).
Review: Lesson 7 →
Prove it — test yourself
ArrayList<Integer> L = [10, 20, 30]. What is L after L.remove(1)? Then after L.remove(Integer.valueOf(10))? What do L.size() and L.isEmpty() give after L.clear()?

[10, 30] — remove(int) removes by index; then [30] — remove(Object) removes by value. After clear: size 0, isEmpty true.

list = [Red, Pink, Black, Blue, Red]: get(1), indexOf("Red"), lastIndexOf("Red"), indexOf("White")?

Input: 4 4 2 4 2 0. What is printed after “The distinct integers are: ”? Which method prevents duplicates?

What is <E> in ArrayList<E> called? Write an ArrayList for strings in two ways.

Which compile? (1) ArrayList s = new ArrayList(); s.add("one"); String n = s.get(0); (2) the same with (String) s.get(0) (3) ArrayList<String> s = new ArrayList<String>(); s.add("one"); String n = s.get(0);

Write pop() for MyStack (field ArrayList<Object> list). After push(1); push(2); push(3); what do pop() and then peek() return?

Turn String[] array = {"red", "green", "blue"}; into an ArrayList, and an ArrayList list back into an array.
