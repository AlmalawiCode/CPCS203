الكتابة إلى الملفات باستخدام PrintWriter

حفظ البيانات في الملفات بشكل دائم

الوحدة 3 • الدرس 4 من 5

1 PrintWriter: قلمك السحري

أخرج المعلّم قلمًا سحريًا يُسمى PrintWriter.

وقال: "هذا يتيح لنا كتابة النص داخل ملف، تمامًا كما يكتب System.out.print النص على الشاشة."

الفكرة الأساسية

تمامًا كما نستخدم System.out.println() للطباعة على الطرفية (Console)، نستخدم PrintWriter "للطباعة" في ملف. والدوال متطابقة تقريبًا!

الكتابة إلى الطرفية (Console)
System.out.println( "Hello!" ); System.out.print( "World" );
الكتابة إلى ملف
writer.println( "Hello!" ); writer.print( "World" );

2 إنشاء كائن PrintWriter

هناك عدة طرق لإنشاء كائن PrintWriter:

import java.io.File; import java.io.PrintWriter; import java.io.FileNotFoundException; public class WriteFile { public static void main(String[] args) { try { // Method 1: Using File object File myFile = new File("output.txt"); PrintWriter writer = new PrintWriter(myFile); // Method 2: Directly with filename PrintWriter writer2 = new PrintWriter("output.txt"); // Write to the file writer.println("Hello, file!"); // IMPORTANT: Close the writer! writer.close(); } catch (FileNotFoundException e) { System.out.println("Error creating file!"); } } }
إنشاء الملف

إذا لم يكن الملف موجودًا، فإن PrintWriter سيقوم بإنشائه. أما إذا كان موجودًا بالفعل، فإن PrintWriter سيقوم بالكتابة فوقه (ممّا يمحو المحتوى القديم)!

3 دوال PrintWriter

الدالة الوصف
print(data) تكتب البيانات دون إضافة سطر جديد في النهاية
println(data) تكتب البيانات متبوعةً بسطر جديد
printf(format, args) تكتب مخرجات منسّقة (مثل printf في لغة C)
flush() تفرض كتابة البيانات المخزّنة مؤقتًا إلى الملف
close() تفرغ المخزن المؤقت ثم تغلق الكاتب (writer)

مثال: استخدام دوال الكتابة المختلفة

PrintWriter writer = new PrintWriter("output.txt"); // println - adds newline writer.println("Hello, file!"); // print - no newline writer.print("Writing some more text..."); writer.println(" And a new line!"); // printf - formatted output String name = "Ahmed"; int score = 95; writer.printf( "%s scored %d points%n", name, score ); writer.close();
📄 output.txt (Result)
Hello, file!
Writing some more text... And a new line!
Ahmed scored 95 points

4 لماذا يجب أن نغلق أو نفرّغ المخزن؟

أفشى المعلّم هذا السر: "عندما تكتب بيانات إلى ملف، قد تحتفظ Java ببعض تلك البيانات في منطقة مؤقتة تُسمى المخزن المؤقت (Buffer). وهذا يجعل الكتابة أكثر كفاءة."

"لكن إن لم تقل أبدًا 'اكتب كل شيء إلى الملف الآن' (عبر الإغلاق أو التفريغ)، فقد تبقى البيانات في ذلك المخزن المؤقت ولا تظهر أبدًا في الملف الفعلي!"

فهم المخزن المؤقت (Buffer)
شيفرتك تكتب:
writer.println("Hello")
→
المخزن المؤقت (الذاكرة):
"Hello\n"
→
الملف (القرص):
After close()/flush()
بدقّة أكبر: مَن يُخزِّن البيانات مؤقتًا؟ (طبقتان)

في الحقيقة هناك طبقتان من التخزين المؤقت، وليست طبقة واحدة:

1) مخزن Java (في ذاكرة التطبيق): أصناف مثل BufferedWriter وPrintWriter تحتفظ بالبيانات في ذاكرة الـ JVM. استدعاء flush() يُفرِّغ هذا المخزن ويُمرِّر البيانات إلى نظام التشغيل — لكنه لا يضمن الكتابة على القرص. تقول وثائق Java عن flush(): «flushing the stream guarantees only that bytes previously written to the stream are passed to the operating system for writing; it does not guarantee that they are actually written to a physical device such as a disk drive.»

2) مخزن نظام التشغيل (kernel / page cache): بعد أن تُمرِّر Java البيانات، يحتفظ بها نظام التشغيل في مخازنه قبل كتابتها فعليًا على القرص. لإجبار الكتابة على القرص الفعلي تُستخدَم FileDescriptor.sync() أو FileChannel.force().

باختصار: Java تُخزِّن مؤقتًا في ذاكرة التطبيق، ونظام التشغيل يُخزِّن مؤقتًا في نواته؛ flush() ينقل من الأولى إلى الثاني، وsync()/force() ينقل من الثاني إلى القرص.

المصدر: توثيق Oracle الرسمي (Java SE API) — OutputStream.flush() وFileDescriptor.sync().

خطأ شائع!

إذا نسيت استدعاء close()، فقد يكون ملفك فارغًا أو غير مكتمل! فالبيانات لا تزال قابعة في المخزن المؤقت، تنتظر أن تُكتب.

عندما يريد برنامج Java كتابة بيانات إلى القرص الصلب، فإنه يستدعي في النهاية استدعاءات النظام (System Calls) التي يوفّرها نظام التشغيل. تتخاطب أصناف الإدخال/الإخراج في Java مع الآلة الافتراضية (JVM)، التي تستدعي بدورها استدعاءات نظام الإدخال/الإخراج للملفات الخاصة بنظام التشغيل (مثل write() على Linux أو WriteFile() على Windows). تمرّر استدعاءات النظام هذه البيانات إلى نواة نظام التشغيل (OS Kernel)، التي تتفاعل مع نظام الملفات ومشغّل القرص (Disk Driver).

ملاحظة: ستُغطّى التفاصيل الدقيقة في مقرر أنظمة التشغيل.

5 مثال متكامل: تقرير درجات الطلاب

دعونا نكتب برنامجًا يُنشئ ملف تقرير للدرجات:

import java.io.PrintWriter; import java.io.FileNotFoundException; public class GradeReport { public static void main(String[] args) { // Student data String[] names = {"Ahmed", "Sara", "Mohammed"}; int[] scores = {85, 92, 78}; try { PrintWriter writer = new PrintWriter("report.txt"); // Write header writer.println("=== Grade Report ==="); writer.println(); // Write each student for (int i = 0; i < names.length; i++) { writer.printf( "Student: %-10s Score: %d%n", names[i], scores[i] ); } // Calculate and write average double sum = 0; for (int score : scores) { sum += score; } double average = sum / scores.length; writer.println(); writer.printf( "Class Average: %.2f%n", average ); writer.println("===================="); // IMPORTANT: Close the writer! writer.close(); System.out.println("Report saved to report.txt"); } catch (FileNotFoundException e) { System.out.println("Error creating report file!"); } } }
📄 report.txt (Output File)
=== Grade Report ===

Student: Ahmed Score: 85
Student: Sara Score: 92
Student: Mohammed Score: 78

Class Average: 85.00
====================

6 القراءة والكتابة معًا

كثيرًا ما تحتاج إلى القراءة من ملف والكتابة إلى ملف آخر:

import java.io.File; import java.io.PrintWriter; import java.io.FileNotFoundException; import java.util.Scanner; public class CopyAndModify { public static void main(String[] args) { try { // Open input file for reading Scanner reader = new Scanner( new File("input.txt") ); // Open output file for writing PrintWriter writer = new PrintWriter( "output.txt" ); int lineNum = 1; while (reader.hasNextLine()) { String line = reader.nextLine(); // Add line numbers to each line writer.printf( "%3d: %s%n", lineNum, line ); lineNum++; } // Close both! reader.close(); writer.close(); System.out.println("File processed successfully!"); } catch (FileNotFoundException e) { System.out.println( "Error: " + e.getMessage() ); } } }
أفضل ممارسة

أغلق دائمًا كائنات القراءة والكتابة عند الانتهاء منها. من الأنماط الجيدة أن تغلقها بالترتيب العكسي لفتحها (أغلق الكاتب writer أولًا، ثم القارئ reader).

7 الخلاصة

أهم النقاط
  • ✓ PrintWriter يكتب النص إلى الملفات مثلما يكتب System.out إلى الطرفية.
  • ✓ استخدم print() وprintln() وprintf() لكتابة البيانات.
  • ✓ تُخزَّن البيانات مؤقتًا - أي تُحفظ بشكل مؤقت قبل كتابتها إلى القرص.
  • ✓ أغلق دائمًا close() الكاتب لضمان حفظ البيانات!
  • ✓ ينشئ PrintWriter ملفات جديدة أو يكتب فوق الملفات الموجودة.

وهكذا تعلّم الطالب:

  • الملفات تحفظ البيانات حتى بعد توقف البرامج عن العمل
  • يتيح لنا الصنف File استكشاف خصائص الملف
  • يقرأ Scanner من الملفات كما يقرأ من لوحة المفاتيح
  • يكتب PrintWriter إلى الملفات مثلما يكتب System.out إلى الشاشة
  • أغلق دائمًا كائنات الكتابة لحفظ البيانات بشكل صحيح!
