Q8 Write a Method — Count the Lines Containing a Word HARD CLO 2SO-a 8 marks

Write a Java method that counts how many lines of a text file contain a given word. The method should accept two parameters — the file name as a String and the word as a String — and return an int. If the file does not exist the method must return −1 instead of crashing. Also, indicate how to invoke the method from the main method.

notes.txt
Java is fun I like Java Python is fine

For example, with the file above and the word "Java", the method returns 2.

Write your complete method, then the call from main:
Model Answer — Q8
public static int countLines(String fileName, String word) {
    File file = new File(fileName);
    if (!file.exists())
        return -1;

    int count = 0;
    try {
        Scanner input = new Scanner(file);
        while (input.hasNextLine()) {
            String line = input.nextLine();
            if (line.contains(word))
                count++;
        }
        input.close();
    } catch (FileNotFoundException e) {
        return -1;
    }
    return count;
}

// invocation from main:
System.out.println(countLines("notes.txt", "Java"));

Rubric: correct signature and return type 2 · exists() guard returning −1 1.5 · Scanner built from the File 1 · hasNextLine()/nextLine() loop 1.5 · contains test and increment 1 · correct call from main 1. A solution that declares throws FileNotFoundException instead of catching loses the 1.5 guard marks, because it no longer returns −1.

Model Answer — Q9
public static void filter(String inFile, String outFile, double limit)
                                        throws FileNotFoundException {
    Scanner     input = new Scanner(new File(inFile));
    PrintWriter out   = new PrintWriter(new File(outFile));

    while (input.hasNext()) {
        String name  = input.next();
        double total = input.nextDouble() + input.nextDouble();
        if (total >= limit)
            out.println(name);
    }

    input.close();
    out.close();
}

Rubric: signature with throws 1.5 · Scanner on the input file 1 · PrintWriter on the output file 1 · hasNext() loop 1.5 · reading all three tokens in the right order 1 · condition and println 1 · closing both 1. A teacher keeps the file scores.txt shown in Q9. Each line is name quiz1 quiz2 and the maximum total is 40.

Write a complete Java program in a class called ExamFinal (imports, class header and main) that:

  2. writes each student whose total is at least 20 into passed.txt, in the form name total;
  3. writes every other student into failed.txt, in the same form;
  4. prints on the screen: Passed: n Failed: m
passed.txt
Mona 29.5 Faisal 23.5 Lama 34.5

Yousef 19.5
screen

Model Answer — Q10
import java.io.File;
import java.io.PrintWriter;
import java.io.FileNotFoundException;
import java.util.Scanner;

public class ExamFinal {
    public static void main(String[] args) throws FileNotFoundException {

        Scanner     input  = new Scanner(new File("scores.txt"));
        PrintWriter passed = new PrintWriter(new File("passed.txt"));
        PrintWriter failed = new PrintWriter(new File("failed.txt"));

        int nPassed = 0, nFailed = 0;

        while (input.hasNext()) {
            String name  = input.next();
            double total = input.nextDouble() + input.nextDouble();

            if (total >= 20) {
                passed.println(name + " " + total);
                nPassed++;
            } else {
                failed.println(name + " " + total);
                nFailed++;
            }
        }

        System.out.println("Passed: " + nPassed + "  Failed: " + nFailed);

        input.close();
        passed.close();
        failed.close();
    }
}

Rubric: imports, class header and main with throws 1.5 · Scanner on scores.txt 1 · two PrintWriter objects 2 · loop reading name and both marks 2 · if/else routing each record to the right file 2 · two counters and the final screen line 1 · closing all three streams 0.5. Q11 Buffering and Flushing — Short Answer MEDIUM CLO 2SO-a 6 marks · 3 each

(a) A student writes 100 lines with out.println(...) and the program then ends without calling out.close(). The file report.txt is created, but when it is opened it is empty. Explain in one or two sentences why. [3 marks]

(b) A PrintWriter keeps its own buffer inside the Java program, and the operating system keeps a second buffer of its own. Name the method that empties the Java buffer into the operating system, and state whether calling it guarantees the bytes are already physically on the disk. [3 marks]

Model Answer — Q11

(a) println does not write straight to the disk. The text collects in the PrintWriter's in-memory buffer and is only handed on when that buffer fills up or when flush() or close() is called. Because neither was called, the buffered text was discarded when the program exited, so the file stayed empty.

(b) The method is flush(). No — it only moves the data from the Java buffer into the operating system's own buffer. The operating system still decides when to write it to the physical disk.

(a) 3 marks: 2 for naming the buffer as the cause, 1 for stating that exiting without close() loses it. (b) 1.5 for flush(), 1.5 for correctly saying it does not reach the physical disk. Accept "the OS page cache" as the second layer.
