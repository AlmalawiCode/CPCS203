صنف الملف (The File Class)

فتح الملفات وفهم المسارات

الوحدة 3 • الدرس 2 من 5

1 فتح ملف باستخدام صنف الملف (File Class)

شرح المعلم كيفية الوصول إلى ملف نصي في Java.

قال: "أولًا، ننشئ كائن ملف (File object) يشير إلى المكان الذي يُخزَّن فيه ملفنا."

ما هو صنف الملف (File Class)؟

يمثل الصنف File في Java مسار ملف أو مجلد. وهو لا يحتوي فعليًا على بيانات الملف — بل هو أشبه بـ مؤشر (pointer) أو مقبض (handle) لموقع الملف.

// Import the File class import java.io.File; // Create a File object pointing to "data.txt" File myFile = new File("data.txt");
مهم أن تفهم

إنشاء كائن File لا يُنشئ الملف الفعلي على القرص! إنه ببساطة يُنشئ كائن Java يمثّل مسار الملف. وقد يكون الملف موجودًا وقد لا يكون.

2 المسارات المطلقة مقابل النسبية (Absolute vs Relative Paths)

عند تحديد موقع ملف، لديك خياران:

📂 المسار المطلق (Absolute Path)

الموقع الكامل بدءًا من جذر نظام الملفات.

// Windows File f = new File("C:/Users/Student/data.txt"); // Linux/Mac File f = new File("/home/student/data.txt");
📁 المسار النسبي (Relative Path)

الموقع بالنسبة إلى مجلد مشروعك.

// Same folder as code File f = new File("data.txt"); // In subfolder "resources" File f = new File("resources/data.txt");
مثال على بنية مجلد المشروع
MyProject/ ├── src/ │ └── Main.java ← Your code runs here ├── resources/ │ └── data.txt ← File("resources/data.txt") └── notes.txt ← File("notes.txt")
مشكلة المسارات المطلقة

إذا استخدمت "C:/Users/Ahmed/Documents/data.txt" ثم شاركت الكود مع صديق، فلن يعمل على جهازه لأنه لا يملك نفس بنية المجلدات!

ميزة المسارات النسبية

المسارات النسبية قابلة للنقل (portable) — فهي تعمل على أي جهاز طالما بقيت بنية مجلد المشروع كما هي. فضّل دائمًا المسارات النسبية!

3 التحقق من وجود ملف

قبل القراءة من ملف، من الممارسات الجيدة التحقق مما إذا كان موجودًا بالفعل:

File myFile = new File("data.txt"); if (myFile.exists()) { System.out.println("File found!"); } else { System.out.println("File not found. Please check the path!"); }

أوضح المعلم: "فكّر في الأمر مثلما يتحقق مستكشف ويندوز (Windows Explorer) من الملفات على جهازك. صنف File يتيح لنا أشياء مشابهة — استكشاف خصائص الملفات، والتحقق من وجودها، ومعرفة حجمها، وأكثر من ذلك."

4 توابع مفيدة في صنف الملف (File Class)

يوفر صنف File العديد من التوابع المساعدة:

التابع القيمة المُرجعة الوصف
exists() boolean يُرجع true إذا كان الملف/المجلد موجودًا
canRead() boolean يُرجع true إذا كان الملف قابلًا للقراءة
canWrite() boolean يُرجع true إذا كان الملف قابلًا للكتابة
isDirectory() boolean يُرجع true إذا كان مجلدًا
isFile() boolean يُرجع true إذا كان ملفًا
getName() String يُرجع اسم الملف
getAbsolutePath() String يُرجع المسار الكامل
length() long يُرجع حجم الملف بالبايت
delete() boolean يحذف الملف

مثال: استكشاف خصائص الملف

import java.io.File; public class FileExplorer { public static void main(String[] args) { File myFile = new File("data.txt"); System.out.println("File name: " + myFile.getName()); System.out.println("Exists: " + myFile.exists()); System.out.println("Full path: " + myFile.getAbsolutePath()); System.out.println("Is file: " + myFile.isFile()); System.out.println("Is directory: " + myFile.isDirectory()); System.out.println("Can read: " + myFile.canRead()); System.out.println("Size (bytes): " + myFile.length()); } }
مثال على المخرجات (إذا كان الملف موجودًا)
File name: data.txt Exists: true Full path: C:\Users\Student\MyProject\data.txt Is file: true Is directory: false Can read: true Size (bytes): 156

5 إنشاء الملفات والمجلدات

يمكنك أيضًا إنشاء ملفات ومجلدات جديدة باستخدام صنف File:

import java.io.File; import java.io.IOException; public class CreateFiles { public static void main(String[] args) { // Create a new file File newFile = new File("newfile.txt"); try { if (newFile.createNewFile()) { System.out.println("File created!"); } else { System.out.println("File already exists."); } } catch (IOException e) { System.out.println("Error creating file."); } // Create a new directory File newDir = new File("myFolder"); if (newDir.mkdir()) { System.out.println("Directory created!"); } } }
ملاحظة حول الاستثناءات

يمكن للتابع createNewFile() أن يرمي استثناء IOException، والذي يجب أن نتعامل معه باستخدام try-catch. سنتعلم المزيد عن الاستثناءات في وحدة لاحقة!

6 الملخّص

النقاط الرئيسية
  • ✓ يمثل صنف الملف (File class) مسار ملف أو مجلد (وليس المحتوى الفعلي).
  • ✓ تعطي المسارات المطلقة الموقع الكامل بدءًا من الجذر (أقل قابلية للنقل).
  • ✓ تكون المسارات النسبية نسبةً إلى مجلد مشروعك (أكثر قابلية للنقل).
  • ✓ تحقّق دائمًا من وجود الملف باستخدام exists() قبل محاولة قراءته.
  • ✓ يوفر صنف File توابع لاستكشاف خصائص الملفات وإنشاء الملفات/المجلدات.
