Q2 Short Answers — Why Generics? EASY CLO 12SO-a 6 marks · 1 each

(a) State the key benefit of generics in one sentence.

(b) A class stores its data in a field of type Object. Give two problems the user of this class faces when reading the data back.

(c) In public class Glass<T>, what is T called? By convention, what do the letters E, K and V stand for?

(d) Why can we not write Glass<int>? What do we write instead?

(e) In Glass<Juice> g = new Glass<>(); what is <> called, and how does the compiler know the type?

(f) Name the three things in Java that can be made generic. Are generics one of the four OOP pillars?

Model Answer — Q2

(a) Generics let the compiler detect type errors at compile time instead of at run time (and remove the need for casting).

(b) Every read needs a cast (e.g. (Juice) g.getLiquid()), and a wrong cast compiles but crashes at run time with ClassCastException.

(c) T is a type parameter (a placeholder for a type). E = Element, K = Key, V = Value.

(d) A type argument must be a reference type, not a primitive. Use the wrapper class: Glass<Integer> (autoboxing converts int values for us).

(e) The diamond operator; the compiler takes the type from the declared type on the left (Glass<Juice>).

(f) Classes, methods and interfaces. No — generics are a language feature (since JDK 1.5), not an OOP pillar.

1 mark each; (b), (c) and (f) need both parts for the full mark (½ each).

Model Answer — Q8
public static <T> int countMatches(T[] list, T target) {
    int count = 0;
    for (T e : list) {
        if (e.equals(target)) {
            count++;
        }
    }
    return count;
}

public static <T> void swap(T[] list, int i, int j) {
    T temp = list[i];
    list[i] = list[j];
    list[j] = temp;
}

(c) Compilation error. T can only stand for a reference type, and an int[] is not a T[] (javac: method countMatches cannot be applied to given types; found: int[], int). Fix: Integer[] ages = {19, 20, 19}; → prints 2.

public class Pair<K, V> {
    private K key;
    private V value;

    public Pair(K key, V value) {
        this.key = key;
        this.value = value;
    }
    public K getKey() {

    public V getValue() {
